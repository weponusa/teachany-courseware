热量计算：从可观察现象到可测变量

同样晒太阳，为什么沙比水烫得快？热量到底怎么算？

Learning Objectives

学习目标

  • 能用 Q=cmΔt 计算物体吸收或放出的热量
  • 理解比热容的意义：单位质量升高 1℃ 吸收的热量
  • 能解释水和沙升温快慢不同等生活现象
真实情境

夏天沙滩烫脚，海水却没那么烫

同样暴晒，沙烫得快，水升温慢。不是太阳“偏心”，而是不同物质比热容不同：升高相同温度，水往往要吸收更多热量。

已有经验

烧开一壶水要很久；铁锅却很快烫手。

真正卡点

把“温度高”和“热量多”混为一谈；算题时忘了 Δt 是变化量，或单位不统一。

本课任务

抓住 Q=cmΔt → 理解 c → 会算、会解释。

一句话：热量是过程量；比较升温快慢，先看比热容与质量。

核心概念

Q = c m Δt

公式

Q=cmΔt。Q 热量，c 比热容，m 质量，Δt 温度变化量。

比热容 c

单位质量的某种物质温度升高 1℃ 吸收的热量。水的比热容较大。

生活

水升温慢、降温也慢，可调节气温；沙漠昼夜温差大，与沙比热容较小有关。

知识精讲

热量计算

物体吸收或放出的热量用 Q = cmΔt 计算，其中 c 是比热容、m 是质量、Δt 是温度变化量。吸热时 Δt = t 末 − t 初，放热时 Δt = t 初 − t 末，计算结果为正值。燃料完全燃烧放出的热量用 Q = mq，q 为热值。

方法与范例

方法：单位统一，温差取绝对值

代入前把质量换算成 kg、温度差算成 ℃。多步问题（如加热水到沸腾）先求 Δt 再乘 cm，涉及燃料时用 Q 放 = mq 与 Q 吸 建立效率关系。

范例：2 kg 水升温 10 ℃，c = 4.2×10³ J/(kg·℃)，Q = cmΔt = 4.2×10³ × 2 × 10 = 8.4×10⁴ J。

常见误区：常见误区是把温度值当成温度差代入，例如直接用 t 末 而不是 Δt。

易混辨析

温度高 ≠ 热量多

  • 温度：状态量，描述冷热程度。
  • 热量：过程量，描述传热过程中转移的能量。
  • Δt：必须是变化量，不是末温本身。
  • 记忆锚点：先找 m、c、Δt，再代入。
迁移任务

解释：海边昼夜温差为什么往往比沙漠小？

用比热容与 Q=cmΔt 写 3–4 句话：白天吸热、夜晚放热时，水和沙谁温度变化更剧烈。

Specific Evidence

热量计算：从可观察现象到可测变量：本课专属证据包

课标锚点

通过实验探究理解比热容概念，掌握热量计算公式 Q = cmΔt 和 Q = mq 的应用，能解释生活中与热量相关的现象。

具体案例

用相同酒精灯加热 100g 铜块和 100g 铝块 3 分钟，铝块温度升高 12℃，铜块仅升高 5℃，证明不同物质比热容不同（c 铜=0.39×10³J/(kg·℃)，c 铝=0.88×10³J/(kg·℃)）。

分析方法

解题四步骤：1.判断吸放热方向 2.正确写出 Δt 表达式 3.查表确定比热容 4.统一单位代入计算。

避坑提醒

学生常混淆温度变化量 Δt 正负，误将 t 初−t 末用于吸热计算，导致结果符号错误。

📖 现象初探

And：学生知道夏天沙滩比海水烫脚

But：不清楚为什么相同阳光照射下温度不同

Therefore：建立热量与温度差异的直观联系

热量是能量转移的量度，而温度是物体冷热程度。比如将100g铁勺和100g木勺同时放入热汤，铁勺柄很快烫手（比热容0.46J/g℃），木勺柄仍温凉（约1.8J/g℃），说明相同质量吸收相同热量时，比热容小的物体温升更明显。

🌍 煮火锅时，肥牛片比白菜熟得快——肉类比热容（约2J/g℃）小于蔬菜（约3.8J/g℃），相同火力下升温更快。

相同质量的铜块和铝块晒1小时太阳，哪个温度更高？（比热容：铜0.39，铝0.88）

📖 公式拆解

And：已认识Q=cmΔt公式符号

But：不理解各变量如何影响结果

Therefore：用控制变量法理解公式内涵

热量Q就像'能量包裹'大小，取决于三个因素：①比热容c是材料'吸热能力'——给200g水和油（c水=4.2，c油=2.0）同时加热5分钟，水温只升12℃，油温却升25℃；②质量m是'接收包裹人数'——烧开1壶水（2kg）比半壶（1kg）需要更多热量；③Δt是'每人分到多少'——洗澡水从20℃升到40℃比升到30℃要多吸1倍热量。

🌍 电饭煲煮饭时，米水比例要严格——水太少（m小）或火力太大（Δt大）都容易烧焦。

📖 对比实验

And：会套用公式计算

But：难以设计实验验证规律

Therefore：培养变量控制实验思维

设计实验要明确变量：①控制变量——研究c影响时，保持m、Δt相同。例如用相同加热器给50g铜（c=0.39）和铁（c=0.46）块加热，记录达到50℃的时间；②因变量——用温度计测量Δt，用秒表记录时间（反映Q）。关键细节：加热器功率要稳定，初始温度要相同，用隔热材料减少散热。

🌍 奶茶店用蒸汽加热牛奶时，全脂奶（c≈3.8）比脱脂奶（c≈4.0）热得更快——商家通过调整蒸汽时间控制温度。

📖 解释现象

And：能计算单一物体吸热

But：不会分析复杂自然现象

Therefore：综合应用解释生活案例

分析现象要抓关键因素：①海边昼夜温差小是因为海水c大（4.2），白天吸收大量热量但温升小，夜晚缓慢放热；沙漠沙子c小（0.8），白天迅速升温，夜晚急剧降温。②计算示例：1kg海水和沙子各吸收8400J热量，海水Δt=8400/(4200×1)=2℃，沙子Δt=8400/(800×1)=10.5℃。

🌍 汽车水箱用水冷却发动机——每kg水升高1℃能吸收4200J热量，比油类冷却剂效率高得多。
