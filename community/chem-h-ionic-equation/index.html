Learning Objectives

学习目标

  • 能按步骤把化学方程式改写为净离子方程式
  • 能判断哪些物质应拆写、哪些应保留

核心模块 1

写离子方程式：拆强电解质，保留沉淀、气体、弱电解质

可溶于水的强酸、强碱、可溶性盐拆成离子；沉淀、气体、单质、弱电解质、氧化物写化学式。先写完整化学方程式并配平，再改写成离子形式，最后删去旁观离子得到净离子方程式。电荷守恒与原子守恒都要检查，这是发现漏配平的最快方法。

例题拆解：Ba(OH)₂+H₂SO₄→BaSO₄↓+2H₂O 的净离子式：Ba²⁺+2OH⁻+2H⁺+SO₄²⁻→BaSO₄↓+2H₂O。

核心模块 2

常见易错：过量、量不足与能否拆开要看清

多元弱酸酸式盐、氨水、醋酸等不能按强电解质随意全拆。澄清石灰水与过量 CO₂、少量 CO₂ 产物不同，离子方程式也不同。题干若强调“适量/过量”，先判断产物，再决定拆哪些物质。

例题拆解：少量 CO₂ 通入 Ca(OH)₂：CO₂+Ca²⁺+2OH⁻→CaCO₃↓+H₂O；过量时生成 Ca(HCO₃)₂。

马上练：用模型判断

写离子方程式时，醋酸应写成？

核心模块 3

用守恒快速验算：原子守恒 + 电荷守恒

配平后的离子方程式，左右原子种类与数目相等，左右电荷代数和相等。若电荷不守恒，多半是某离子系数写错或把不该拆的物质拆了。氧化还原离子方程式还要保证得失电子数相等。

例题拆解：2Fe³⁺+Fe→3Fe²⁺：原子与电荷均守恒（左+6，右+6）。

知识精讲

离子方程式

离子方程式表示电解质在溶液中的有效离子反应。写步骤：写完化学方程式→把易溶强电解质拆成离子→删去未反应离子→检查质量与电荷守恒。弱酸、弱碱、沉淀、气体、单质、氧化物一般不拆。

方法与范例

方法：拆与不拆要分明

强酸强碱可溶性盐拆；弱酸（如 H₂CO₃、醋酸）、NH₃·H₂O、水、沉淀、气体不拆。配平后检查原子个数与电荷总数。复分解需满足生成水、气体或沉淀。

范例：CaCO₃+2HCl=CaCl₂+H₂O+CO₂↑ 写成 CaCO₃+2H⁺=Ca²⁺+H₂O+CO₂↑（CaCO₃、CO₂、H₂O 不拆）。

常见误区：常见误区是把弱酸弱碱也拆成离子，或忽略电荷守恒。醋酸、氨水等不能拆。

马上练：辨析要点

下列书写正确的做法是？

Five Lens

深层理解：五镜头看本质

  • 看见它：AgNO₃ + NaCl = AgCl↓ + NaNO₃ 的净离子式是 Ag⁺ + Cl⁻ = AgCl↓。
  • 拆开它：BaCl₂ 与 Na₂SO₄ 的净离子式是 Ba²⁺ + SO₄²⁻ = BaSO₄↓。
  • 比较它：CuSO₄ 与 NaOH 反应要写成 Cu²⁺ + 2OH⁻ = Cu(OH)₂↓，OH⁻ 前的 2 不能漏。
  • 迁移它：把这个判断标准用到一个新的实验或生活场景中。

记忆锚点：四步法：写、拆、删、查；最后查原子，也查电荷。

易错提醒：常见错误：把弱电解质 H₂O、沉淀 AgCl 也拆成离子，导致净离子方程式失去反应本质。

具体案例

氯化钠溶液与硝酸银溶液反应生成白色沉淀（AgCl），离子方程式为Ag⁺ + Cl⁻ → AgCl↓，删去未反应的Na⁺和NO₃⁻离子

分析方法

先写化学方程式，再将易溶强电解质拆为离子，删除旁观离子后检查原子守恒和电荷守恒

避坑提醒
