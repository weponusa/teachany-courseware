📖 模块一：合并同类项
📖 AND（背景）

在算术中，2苹果 + 3苹果 = 5苹果，但 2苹果 + 3橙子不能合并成5个同类水果。代数中的"同类项"就是这个道理。

⚡ BUT（冲突）

当代数式中有很多项时，如何快速化简？比如 3x² + 2x − x² + 5x − 1 该如何处理？

💡 THEREFORE（解决）

把同类项的系数相加（利用分配律），这就是合并同类项。

📌 合并同类项法则

合并同类项：把系数相加，字母和指数不变。

  • 依据：分配律 ma + na = (m+n)a
  • 例：3x + 5x = (3+5)x = 8x
  • 例：3x² - x² = (3-1)x² = 2x²
化简：3x² + 2x − x² + 5x − 1
↓ 找同类项（颜色相同的是同类项）
3x² 和 -x² 是同类项， 2x 和 5x 是同类项， -1 单独一项
↓ 合并
(3-1)x² = 2x² (2+5)x = 7x -1
↓ 结果
2x² + 7x − 1
⚠️ 反例镜——不能合并的情况

只有同类项才能合并，不同类的不能合并！

✗ 错误：3x + 2 = 5x（x和常数不同类）
✗ 错误：3x² + 2x = 5x³（合并时字母和次数不变！）
✓ 正确：3x² + 2x² = 5x²（系数相加，x²不变）

📖 模块二：去括号法则
⚡ BUT（冲突）

在整式加减中，经常遇到括号。括号前是正号还是负号，处理方式完全不同，稍不注意就会出错！

📌 去括号法则

  1. 括号前是 + 号：去掉括号，括号内各项符号不变
  2. 括号前是 − 号：去掉括号，括号内各项符号全部变号
📐 例1：正号前的括号
+(3x − 2y + 1)
= +3x − 2y + 1（符号不变）
= 3x − 2y + 1
📐 例2：负号前的括号
−(3x − 2y + 1)
= −3x + 2y − 1（每项都变号！）
= -3x + 2y - 1
🔬 放大镜——为什么要变号？

本质是分配律：−(3x − 2y + 1) = (−1)×(3x − 2y + 1)

= (−1)×3x + (−1)×(−2y) + (−1)×1
= −3x + 2y − 1
记忆口诀："负号进括号，括号内变天地"
去括号并化简：5x − (3x − 2) + 4 = ?
📖 模块三：整式加减综合
💡 THEREFORE（解决）

整式加减的完整流程：①去括号 → ②找同类项 → ③合并同类项 → ④化简结果

1

去括号

处理括号，正号不变号，负号全变号

2

找同类项

用下划线或括号标记出同类项（可用不同颜色区分）

3

合并同类项

系数相加，字母和指数不变

4

写最简结果

按次数从高到低排列各项

📐 完整例题：(2x²-3x+1)-(x²+2x-5)
= 2x² - 3x + 1 - x² - 2x + 5（去括号，负号变号）
= (2x²-x²) + (-3x-2x) + (1+5)（找同类项）
= x² - 5x + 6（合并同类项）

整式的概念与组成

整式是由数字、字母通过加、减、乘运算构成的代数表达式，不含除法运算（分母不含字母）。例如：3x² - 2xy + 5 是一个整式，其中 3x²、-2xy 和 5 分别是它的项。而 3/x 不是整式，因为分母含有字母 x。整式中的数字因数称为系数，如 3x² 中 3 是系数；字母部分称为字母因数，如 x²。特别地，单独一个数或字母也是整式，如 -7 或 y。理解整式的组成是进行加减运算的基础。

同类项的识别

同类项是指字母部分完全相同的项。例如：5x²y 与 -2x²y 是同类项，因为它们的字母部分都是 x²y；而 3ab 与 4a²b 不是同类项，因为字母的指数不同。识别同类项的关键是忽略系数，只看字母及其指数。在实际问题中，同类项可能隐藏在不同位置，如 2m + 3n - m + 5n 中，2m 与 -m 是同类项，3n 与 5n 是同类项。练习时建议先用不同标记（如下划线或颜色）区分同类项，避免遗漏。

合并同类项的步骤

合并同类项分为三步：1) 识别同类项；2) 系数相加（减法视为加负数）；3) 字母部分不变。例如：合并 4a - 2b + 3a + 6b 时，先识别 4a 与 3a、-2b 与 6b 为同类项，再计算 4+3=7 和 -2+6=4，最终结果为 7a + 4b。注意：若合并后系数为 0，则该项消失（如 5x - 5x = 0）。生活实例：计算购物总价时，同种商品的价格（如 3 个苹果 2 元 + 5 个苹果 4 元）需合并为 8 个苹果 6 元。

去括号法则

括号前是正号时，直接去掉括号且括号内各项符号不变，如 +(2x - 3) = 2x - 3；括号前是负号时，去掉括号后括号内各项符号变号，如 -(4y + 5) = -4y - 5。多层括号需从内向外逐层处理，例如：3a - [2b - (a - 4b)] = 3a - [2b - a + 4b] = 3a - (6b - a) = 3a - 6b + a = 4a - 6b。物理中的合力计算也适用此法则：若两个力 F₁ 和 -F₂ 方向相反，总力为 F₁ + (-F₂) = F₁ - F₂。

整式加减的综合运算

综合运算顺序为：去括号→合并同类项。例如：(5x² - 3x + 2) - (2x² + x - 4) = 5x² - 3x + 2 - 2x² - x + 4 = (5x² - 2x²) + (-3x - x) + (2 + 4) = 3x² - 4x + 6。复杂问题可分段处理，如先合并部分同类项再去括号。实际应用场景：计算长方形与三角形组合图形的周长时，需将各边代数式相加并化简。特别注意：当括号前有系数时，需先用分配律展开，如 2(3y - 1) - 3(y + 2) = 6y - 2 - 3y - 6 = 3y - 8。

整式加减的几何意义

整式的加减可对应几何图形的拼合。例如：边长为 2x 的正方形与长为 x、宽为 3 的长方形拼接后，总周长为 4×2x + 2(x + 3) - 2×3 = 8x + 2x + 6 - 6 = 10x（重叠边需减去）。又如：圆柱体表面积为 2πr² + 2πrh，若两个半径相同、高分别为 h₁ 和 h₂ 的圆柱叠放，总表面积为 2πr² + 2πrh₁ + 2πr² + 2πrh₂ - 2πr² = 2πr² + 2πr(h₁ + h₂)（减去重叠的底面积）。这种数形结合有助于理解抽象运算。

含参数整式的处理

当整式中含有参数（如 k）时，需将参数视为系数的一部分。例如：若 3kx² - 2x 与 5x² + 4x 的和不含 x² 项，则合并后 (3k + 5)x² + 2x 中 3k + 5 = 0，解得 k = -5/3。化学方程式配平也类似：aH₂ + bO₂ → cH₂O 中，通过字母系数满足原子守恒（2a=2c，2b=c）。关键技巧：1) 明确参数与变量的区别；2) 根据条件建立关于参数的方程；3) 解方程时注意参数可能的取值范围。

实际问题的代数建模

将实际问题转化为整式加减的步骤：1) 用字母表示未知量；2) 根据数量关系列式；3) 化简求解。例如：书店第一周售出 (2x + 3) 本书，第二周售出 (x - 5) 本，两周差量为 (2x + 3) - (x - 5) = x + 8。又如：温度计原示数为 t℃，校正后显示 (t + 2.5)℃，实际温度应为 (t + 2.5 - 0.3t) = 0.7t + 2.5（假设存在 0.3t 的系统误差）。建模时需注意单位的统一和实际意义的合理性。

💡 错因诊断

误区1：忽略字母顺序（认为 ab 与 ba 是同类项）。错因：未理解字母因数的顺序不影响同类项判断。诊断：强调字母部分需完全相同，包括指数和顺序。误区2：去括号时仅变首项符号。错因：对分配律理解不完整。诊断：用-(a - b) = -a + b 等例子强化训练。
