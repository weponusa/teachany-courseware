📖 核心概念

📏 什么是周长？

周长是围成一个图形的所有边的总长度。

周长 = 各条边之和
💡 "周"表示一圈，"长"表示长度。周长就是绕图形走一圈的距离。

🔲 长方形周长

长方形有两条长和两条宽。

C = 2 × (长 + 宽)
C = 2长 + 2宽

例：长6cm，宽4cm
周长 = 2×(6+4) = 20cm

⬛ 正方形周长

正方形四边相等。

C = 4 × 边长

🔺 三角形周长

三角形三边之和。

C = a + b + c

⬠ 多边形周长

各边长度之和。

C = 各边之和

📊 常见图形周长公式对比

图形条件周长公式例子（单位cm）
长方形长=a, 宽=b2(a+b)a=5,b=3 → C=16
正方形边=a4aa=6 → C=24
等边三角形边=a3aa=4 → C=12
一般三角形三边a,b,ca+b+c3+4+5=12
🔎 错因诊断

⚠️ 如果你做错了，看看错在哪里：

如果你把周长公式写成(长+宽)而忘了×2，你忘了长方形有两组对边。每条边要算一次，长方形有两条长和两条宽，所以要×2。

💡 自查方法：把答案代回原题验证，如果算出矛盾就说明中间有错误！

知识精讲

周长的认识与计算

周长是封闭图形一周的长度。长方形周长=(长+宽)×2，或长×2+宽×2；正方形周长=边长×4。求周长要把各边长度加起来，注意单位统一。不规则图形可想象“拉直”成一条线来理解周长。

🔬 最优围栏方案

为长10米、宽6米的矩形苗圃设计围栏，现有两种方案：A.全用长2米的栏杆 B.混合使用1米和3米栏杆

方法与范例

方法：量边相加或套公式

规则图形直接用公式；组合图形沿着外轮廓把外露的边长相加，公共边不重复加。先统一长度单位再算，结果是长度单位不是面积单位。

范例：长5厘米、宽3厘米的长方形，周长=(5+3)×2=16厘米；边长4厘米的正方形周长=4×4=16厘米。

常见误区：常见误区是把周长和面积公式混淆，或组合图形把中间的边也加进去。应分清周长是“一周边长之和”，只加外轮廓。

填空题 1

用一根120厘米长的彩带正好围成正方形相框，每条边长____厘米

查看答案与解析

答案：30

正方形周长=边长×4 → 边长=120÷4=30厘米

填空题 2

长方形操场周长300米，已知长是90米，宽是____米

查看答案与解析

答案：60

周长=(长+宽)×2 → 宽=(300÷2)-90=60米

🎯 后测：学会了吗？

完成学习后，用这两道题检验你的掌握程度！

Q1：长4cm宽3cm的长方形，周长是多少？

✅ 长方形周长=(长+宽)×2=(4+3)×2=14cm

Q2：边长5cm的正方形，周长是多少？

✅ 正方形周长=边长×4=5×4=20cm

⚠️ 易错点诊所

❌ 数格子时只数外框不数转角

✅ 转角是两条边的交点，必须重复计算

💡 对'一周'概念理解不完整

❌ 把面积单位（㎡）用在周长上

✅ 周长用长度单位（米/厘米），面积用面积单位

💡 单位概念混淆
