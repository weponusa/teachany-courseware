📖 模块一：一次函数回顾
🎯 ABT引入：
And：你已经学过正比例函数 y=kx。
But：现实中很多问题的起点不是0——手机套餐有月租费，出租车有起步价……
Therefore：我们需要 y = kx + b，加上一个常数b，这就是更一般的一次函数！
y = kx + b（k≠0）
k：斜率（决定倾斜程度）　b：截距（图象与y轴的交点纵坐标）

k>0：从左下到右上

y随x增大而增大

k<0：从左上到右下

y随x增大而减小

✖️ 模块二：图象法解方程组
🔑 核心思想：二元一次方程组的每个方程，都可以看作一次函数。
方程组的解 = 两条直线的交点坐标！
方程组 { y = x + 1
       { y = -x + 3

解 = 两直线交点 = (1, 2)

📊 三种情况对比（对比法）

✅ 唯一解

两直线相交
k₁ ≠ k₂

❌ 无解

两直线平行
k₁=k₂, b₁≠b₂

♾️ 无数解

两直线重合
k₁=k₂, b₁=b₂

🔑 模块三：找交点坐标
🛠️ 方法：联立两函数方程，令 y₁=y₂，解 x，再求 y

例题：求 y=x+1 与 y=-x+3 的交点

步骤1：令两式相等

x + 1 = -x + 3

步骤2：解方程

2x = 2，x = 1

步骤3：代入求y

y = 1 + 1 = 2

结论：交点为 (1, 2)

  2. 代入求 y（相同时的价格）
  3. 当 x < 该值时，哪个商店更便宜？当 x > 该值时呢？
  4. （拓展）在图上标出交点，并分析两段的意义
🔍 深层理解：五镜头看"交点=解"
🔧
拆开它：y = kx + b 由两个量决定——b 是"起点"（图象与 y 轴交点），k 是"走向"（每向右 1 格，y 变化 k 格）。两个方程就是两条这样的直线。
💡
解释它：为什么交点就是方程组的解？因为交点坐标 (x, y) 同时满足两个函数关系式——这正是"方程组的解"的定义。形与数在这里合二为一。
⚖️
比较它：图象法 vs 消元法：图象法一眼看出解的位置和三种情况（相交/平行/重合），但读数可能不准；消元法算出精确值，却少了直观。两种方法互为验算。
👁️
看见它：把 y = 2x + 1 想成一部"楼梯电梯"：从 (0, 1) 出发，每向右走 1 格就上升 2 格。y = -x + 3 则是从 (0, 3) 出发每格下降 1 格。两部电梯相遇的位置，就是交点。
🚀
迁移它：套餐比价（月租型 vs 按量型）、出租车计价（起步价型 vs 纯里程型）、相遇问题（两人从两地出发）——凡是"两种方案比高低"的问题，都是两条直线找交点。

🧠 记忆锚点

口诀：方程组的解哪里找？图象交点跑不了。k 同 b 不同，平行无解；k、b 都相同，重合无数道。

类比：两条直线像两条公交线路，交点就是"换乘站"——它既在 1 号线上、又在 2 号线上。方程组的解，就是同时"坐得上"两条线的那个站。

一次函数的图像

一次函数的图像是一条直线。斜率 k 决定了直线的倾斜方向和程度：k > 0 时，直线从左下向右上倾斜；k < 0 时，直线从左上向右下倾斜。截距 b 决定了直线与 y 轴的交点。例如，函数 y = -x + 3 的图像是一条斜率为 -1、截距为 3 的直线。通过两点可以确定一条直线，因此只需找到两个满足函数的点，就能画出图像。比如 y = 2x - 1，当 x = 0 时 y = -1，当 x = 1 时 y = 1，连接这两点即可。
