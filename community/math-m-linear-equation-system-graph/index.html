本课属于「数与代数」领域函数主题。下面三条内容要求，是本课目标与评价的直接来源。

内容要求 · 一次函数

  1. 结合具体情境体会一次函数的意义，能根据已知条件确定一次函数的表达式；会运用待定系数法确定一次函数的表达式。
  2. 能画一次函数的图象，根据图象和表达式 y = kx + b（k ≠ 0）探索并理解 k > 0 和 k < 0 时图象的变化情况；理解正比例函数。
  3. 体会一次函数与二元一次方程的关系。

相关要求 · 方程与方程组

  • 掌握消元法，能解二元一次方程组。——本课把它与图象法并置，互为验算。
  • 能根据具体问题的实际意义，检验方程的解是否合理。——迁移到交点坐标的检验环节。

学业要求（本课可观测的表现）

  • 能把二元一次方程变形为 y = kx + b 的形式，并说出对应的直线特征；
  • 能画出两个一次函数的图象，由交点位置读出方程组的解，并用代入法验证；
  • 能根据 k、b 的关系判断两直线位置，说明方程组解的个数及理由；
  • 能用一次函数模型比较两种方案，解释交点在真实情境中的意义。

📖 模块一 · 一次函数回顾：k 与 b 各管什么夯实基础

一次函数的一般形式是 y = kx + b（k ≠ 0）。它只有两个参数，各管一件事：

y = kx + b k 斜率：决定倾斜方向与陡缓 —— 每向右走 1 格，y 变化 k 格 b 截距：决定起点高低 —— 图象与 y 轴交点 (0, b) 的纵坐标
图象特征k > 0k < 0
走向从左下斜向右上从左上斜向右下
增减性y 随 x 的增大而增大y 随 x 的增大而减小
经过象限b>0 时经一、二、三；b<0 时经一、三、四b>0 时经一、二、四；b<0 时经二、三、四
为什么 k ≠ 0？如果 k = 0，式子变成 y = b，图象是一条平行于 x 轴的水平线，y 不再随 x 变化，就不属于一次函数了（它是常数函数）。

📌 范例：用待定系数法确定解析式

已知直线经过 (0, 5) 和 (2, 1)，求解析式。
设 y = kx + b。代入 (0, 5)：b = 5。代入 (2, 1)：2k + 5 = 1，得 k = −2。
所以 y = −2x + 5。反过来，已知解析式，取 x = 0 与 x = 1 两点也能描出直线。

🔄 模块二 · 关键一跃：二元一次方程就是一条直线核心概念

这一步是全课的枢纽。请记住下面这条链：

一个二元一次方程 ax + by = c （b ≠ 0） ↓ 移项、两边除以 b 一次函数形式 y = −(a/b)x + c/b ↓ 坐标平面上唯一的一条直线

三个命题，请逐条确认

  1. 二元一次方程有无数组解 —— 对应直线上无数个点；
  2. 每一组解 (x, y) 都是直线上一个点的坐标，点在直线上 ⟺ 坐标满足方程；
  3. 两个方程组成方程组 ⟺ 两条直线；公共解 ⟺ 两直线的交点。

📌 范例：把 2x + y = 5 变成一次函数

移项得 y = 5 − 2x，即 y = −2x + 5，其中 k = −2，b = 5。
取 x = 0 得 (0, 5)，取 x = 1 得 (1, 3)，取 x = 2 得 (2, 1)……这些点连起来就是这条直线。
把它们代回原方程检验：2×0 + 5 = 5 ✓，2×1 + 3 = 5 ✓，2×2 + 1 = 5 ✓。

📊 模块三 · 图象法解方程组：三种情形分类讨论
核心思想：方程组里每个方程都是一条直线，方程组的解 = 两条直线的交点坐标。几条直线怎么摆，决定了方程组有几个解。

三种情形对照（请重点看判定条件一列）

情形两直线位置判定条件（看 k 与 b）方程组解的个数
相交有一个交点k₁ ≠ k₂唯一一组解，就是交点坐标
平行没有交点k₁ = k₂ 且 b₁ ≠ b₂无解
重合有无数个公共点k₁ = k₂ 且 b₁ = b₂无数组解
⚠️ 高频错因：只比 k，忘了比 b
  • 看到 k 相同就下结论「重合」——漏看了 b，k 同 b 不同其实是平行、无解；
  • 把交点坐标写成 (y, x)——横坐标在前，永远是 (x, y)；
  • 从图上估读交点就当答案——图上只能看位置和大概范围，精确解必须代数联立。

🔑 模块四 · 求交点：代数联立三步法方法精讲

两条直线交点的特点是纵坐标相等。所以令 y₁ = y₂，就得到一个关于 x 的一元一次方程。

📌 范例：求 y = x + 1 与 y = −x + 3 的交点

  1. 列式：令 y₁ = y₂，即 x + 1 = −x + 3
  2. 解 x：移项得 2x = 2，x = 1
  3. 求 y：代回任一式，y = 1 + 1 = 2
  4. 检验：代入第二式，−1 + 3 = 2 ✓，与 y = 2 一致

结论：交点坐标为 (1, 2)，即方程组的解是 x = 1，y = 2。

图象法 vs 消元法：不是二选一，是互相验算

方法擅长什么短板
图象法一眼看出解的大致位置，直观判断三种情形交点不在整点上时读数不准，只能估
消元法算出精确值，步骤可书写、可得分看不出「为什么无解」，少了直观

🎯 综合任务 · 两家店的定价交叉点

甲店按 y = 5x + 10 收费，乙店按 y = 3x + 20 收费（x 为件数，y 为总价，单位：元）。

🪜 解题脚手架（按序号写，别跳步）

  1. 令两式相等：5x + 10 = 3x + 20，解出 x（买几件时两家一样贵）
  2. 把 x 代回任一式求 y（此时的总价是多少）
  3. 取 x = 1 和 x = 10 各算一次，判断：件数少于临界值时哪家便宜？多于临界值时呢？
  4. 把结论写成一句完整的话，并说明图象上这一点的含义
🔍 深层理解：五个角度看「交点 = 解」
🔧
拆开它：一次函数只由 k、b 两个数决定——b 是起点（与 y 轴交点），k 是走向（每向右 1 格上升 k 格）。两个方程就是两条这样的直线，比较它们只需比这两组数。
💡
解释它：交点坐标 (x, y) 同时落在两条直线上，也就同时满足两个函数关系式，这恰好是「方程组解」的定义。数与形在这里不是比喻，是同一件事的两种写法。
⚖️
比较它：图象法给方向和范围，消元法给精确数值。先画图判断「有没有解、大概在哪」，再联立算出准确值，最后代回检验——这是最稳的流程。
👁️
看见它：把 y = 2x + 1 想成一部电梯：从 (0, 1) 出发，每向右 1 格上升 2 格；y = −x + 3 是从 (0, 3) 出发、每格下降 1 格的另一部电梯。两部电梯相遇的楼层，就是交点。
🚀
迁移它：套餐比价（月租型 vs 按量型）、出租车计价（起步价型 vs 纯里程型）、相遇问题（两地相向而行）——凡是「两种方案比高低、找临界点」的问题，都是两条直线求交点。
🧠 记忆锚点
方程组的解哪里找？两条直线的交点跑不了。
k 同 b 不同，平行无解莫混淆；k、b 都相同，重合无数不用找。
类比：两条直线像两条公交线路，交点就是「换乘站」——它既在 1 号线上，也在 2 号线上。方程组的解，就是同时能坐上这两条线的那一站。平行线是两条永不相交的线路，所以没有换乘站（无解）；重合是两条线路编号不同、走的却是同一条路，每一站都能换乘（无数解）。
