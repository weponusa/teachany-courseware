🌟 为什么要用字母表示数？

想象一下，小明每天做 a 道题，一周做 7×a 道。不管 a 是几，这个式子都成立！
用字母表示数，可以：
① 概括规律（如：偶数 = 2n）
② 简化表达（如：正方形面积 = a²）
③ 方便计算（代入具体数字）

📖 核心概念

🔤 字母可以表示什么？

  • 任意数：n 可以是 1, 2, 3...
  • 未知数：求 x 的值
  • 变量：随情况变化的量
💡 字母和数字之间的乘号可以省略：
3×a = 3a，a×a = a²

📖 方程是什么

And：学生已掌握加减乘除运算

But：遇到未知数时不会用数学语言表达

Therefore：理解用字母代表数的思想

方程就像数学里的侦探游戏！我们把不知道的数叫'未知数'，用字母（比如x）代替它。比如：小明有5块糖，吃掉一些后还剩2块，吃了多少块？可以写成方程 5 - x = 2。这里的x就像个神秘盒子，我们要算出里面藏着几块糖。记住两个关键：1.必须有等号 2.一定要有未知数。

🌍 妈妈买菜时算账就是方程：'3斤苹果+2斤梨=20元'，如果梨的价格不知道，就可以写3×5 + 2×y = 20（假设苹果5元/斤）

📖 解方程秘诀

And：已认识方程结构

But：不知道怎样找出未知数的值

Therefore：掌握天平平衡原理解方程

解方程就像玩天平玩具！规则很简单：天平两边必须同时做相同变化。比如 x + 3 = 7，左边多了3，我们就在两边同时减去3：x + 3 - 3 = 7 - 3 → x = 4。再检验：4 + 3确实等于7！记住口诀：'左边右边同加减，乘除也要一起变'。注意：除的时候不能除以0哦！

🌍 就像分披萨：如果x+2块=8块，我们拿走2块后，两边都少2块，就知道原来有6块啦！
