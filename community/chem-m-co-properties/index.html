一氧化碳的物理性质

一氧化碳（CO）是一种无色、无味、无臭的气体，密度略小于空气（标准状况下约为1.25 g/L）。它在常温常压下难溶于水，20°C时溶解度仅为0.0026 g/100 mL水。生活中常见的例子是汽车尾气中含有一氧化碳，因其无色无味，容易在密闭车库中积累导致中毒。实验室中可用排水法收集CO，因其溶解性极低。值得注意的是，CO的沸点为-191.5°C，熔点为-205°C，这些特性使其在工业低温应用中具有价值，例如作为制冷剂。

一氧化碳的化学性质：可燃性

一氧化碳具有可燃性，燃烧时发出蓝色火焰，生成二氧化碳（2CO + O₂ → 2CO₂）。该反应放出大量热（ΔH = -283 kJ/mol），因此CO可作为燃料使用。例如，高炉煤气中含20-30%的CO，是钢铁工业的重要能源。生活中，煤气不完全燃烧时会产生CO，若通风不良可能引发中毒或爆炸。实验演示可将CO通入燃烧管点燃，观察到火焰呈蓝色，用澄清石灰水检验产物变浑浊（CO₂与Ca(OH)₂反应）。需注意：CO与空气混合的爆炸极限为12.5%-74%，操作时须严格控制浓度。

一氧化碳的还原性

CO是强还原剂，能将金属氧化物还原为金属。典型反应如Fe₂O₃ + 3CO → 2Fe + 3CO₂（高炉炼铁原理）。实验室可用CO还原氧化铜：CuO + CO → Cu + CO₂，黑色固体变为红色。工业上还用于镍的精炼（NiO + CO → Ni + CO₂）。生活中，汽车尾气催化转化器利用CO还原氮氧化物（2NO + 2CO → N₂ + 2CO₂）。实验注意事项：CO还原金属氧化物需加热，尾气需处理以防中毒。对比H₂的还原性，CO反应温度更高，更适合工业大规模应用。

一氧化碳的毒性机制

CO与血红蛋白（Hb）的结合能力是氧气的240倍，形成碳氧血红蛋白（COHb）后使血液丧失携氧功能。当COHb浓度达10%时出现头痛，60%可致死。中毒案例：冬季燃煤取暖紧闭门窗，CO浓度达0.1%时1小时即危及生命。生物学解释：CO与Hb中铁离子的配位键比O₂更稳定，且COHb解离速度极慢（半衰期4-6小时）。急救措施需立即转移至通风处，吸纯氧或高压氧治疗。对比CO₂毒性：CO₂通过刺激呼吸中枢致死（浓度>10%），而CO是直接阻碍氧运输。

一氧化碳的制取方法

实验室制法：甲酸脱水（HCOOH → CO↑ + H₂O），浓硫酸作脱水剂，可用排水法收集。工业制法：①水煤气反应（C + H₂O → CO + H₂，吸热）；②部分氧化法（2CH₄ + O₂ → 2CO + 4H₂）。例如合成氨厂用后者制取原料气。特殊方法：草酸与浓硫酸共热（H₂C₂O₄ → CO↑ + CO₂↑ + H₂O），需用NaOH溶液除去CO₂。注意事项：所有制备均需通风橱操作，因CO密度与空气相近，不易自然扩散。对比CO₂制取：碳酸盐与酸反应更安全，凸显CO制备的高危险性。

一氧化碳的检测方法

化学检测：①氯化钯试纸变黑（PdCl₂ + CO + H₂O → Pd↓ + CO₂ + 2HCl）；②血液分光光度法测COHb含量。物理检测：电化学传感器（如家用报警器），原理是CO在电极氧化产生电流。工业标准：红外光谱法（CO在2143 cm⁻¹有特征峰）。生活应用：燃气公司定期检查管道泄漏，使用便携式CO检测仪（检测限1-50 ppm）。对比CO₂检测：后者常用石灰水变浑浊法，而CO需更灵敏的专门手段。注意：民间‘醋味判断法’不可靠，因CO本身无味。

一氧化碳的工业应用

主要用途：①冶金还原剂（年消耗量约1亿吨）；②化工原料（制甲醇：CO + 2H₂ → CH₃OH）；③燃料（高热值10700 kcal/m³）。典型案例：费托合成用CO和H₂制烃类（nCO + (2n+1)H₂ → CₙH₂ₙ₊₂ + nH₂O）。新兴应用：CO激光器（波长5-6 μm）用于医疗和科研。环境矛盾：虽然CO是大气污染物（浓度>10 ppm有害），但化工利用可‘变废为宝’。对比CO₂应用：后者更多用于饮料和灭火，而CO的化学转化价值更高。需注意：所有工业应用必须严格密封防泄漏。

一氧化碳的环境影响与防护

自然来源：火山活动、森林火灾（年释放约5亿吨）。人为来源：机动车（占60%）、工业燃烧（30%）。环境标准：中国规定车间允许浓度≤24 ppm（30 mg/m³）。防护措施：①安装强制通风系统；②佩戴CO报警器（如矿用自救器）。典型案例：隧道施工需实时监测CO，浓度超50 ppm必须撤离。对比SO₂污染：CO不形成酸雨，但危害更具隐蔽性。最新技术：光催化氧化（TiO₂+UV将CO→CO₂）用于室内净化。教育要点：强调‘预防优于救治’，因CO中毒往往发现时已晚。
