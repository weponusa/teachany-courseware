焓变与反应热：用 ΔH 表达能量变化

为什么同一个反应反向书写时，ΔH 的符号要反过来？

学习目标

ABT Story

角色任务：能源方案评估师

And 已有经验

你已经能从能量图判断放热和吸热，也知道热化学方程式需要写出反应热。

But 真实卡点

不同反应、不同物质状态、不同计量系数会让热量数值不同；如果不理解 ΔH 的定义，很容易把符号和倍数搞错。

Therefore 本课任务

所以要用 ΔH = H生成物 - H反应物 统一表达焓变，并理解反应热随方程式方向和系数改变。

Core Ideas

核心概念：先抓判断标准

焓变定义

在恒压条件下，反应焓变可近似理解为生成物总焓与反应物总焓之差：ΔH = H产物 - H反应物。

符号意义

ΔH < 0 表示放热，ΔH > 0 表示吸热；反应反向书写时 ΔH 变号。

系数倍数

热化学方程式的系数乘以 k，ΔH 也乘以 k；因为反应热与反应的物质的量成比例。

Five Lens

深层理解：五镜头看本质

  • 看见它：H₂ 与 O₂ 生成水是典型放热反应，反向分解水需要吸热。
  • 拆开它：同样生成 H₂O(l) 和 H₂O(g)，由于状态不同，焓变不同。
  • 比较它：热化学方程式中 1 mol 反应和 2 mol 反应的 ΔH 数值成倍变化。
  • 迁移它：把这个判断标准用到一个新的实验或生活场景中。

记忆锚点：ΔH 看终点减起点：终点低为负，反向写就变号，倍数变也跟着变。

易错提醒：常见错误：把 ΔH 当成固定不随方程式变的常数。热化学方程式反向、倍乘、物质状态变化都会影响 ΔH 表达。

Worked Example

例题拆解：不要先套结论，先找证据

遇到关于「焓变与反应热」的题目，第一步不是回忆一整页笔记，而是把题干里的对象、条件和现象圈出来。对象决定我们讨论的是哪一类粒子、结构或反应；条件决定这个判断能不能成立；现象则提供可验证的证据。

第二步，把证据翻译成化学语言：如果看到颜色、沉淀、气体、能量、速率、平衡移动或官能团变化，就要分别追问它对应的是结构、价态、键型、浓度、温度还是反应路径的变化。

第三步才写结论。结论必须能回答“为什么不是另一个选项”。例如本课的常见误区是：常见错误：把 ΔH 当成固定不随方程式变的常数。热化学方程式反向、倍乘、物质状态变化都会影响 ΔH 表达。 这个误区看似接近正确答案，但它忽略了判断标准中的限定条件。

如果你能解释“为什么同一个反应反向书写时，ΔH 的符号要反过来？”，这节课就真正过关了。

什么是焓变？

焓变（ΔH）是化学反应中系统吸收或释放的热量，单位为千焦/摩尔（kJ/mol）。它反映了反应前后物质内能的变化。例如，甲烷燃烧反应 CH₄ + 2O₂ → CO₂ + 2H₂O 的 ΔH = -890 kJ/mol，负号表示放热。生活中，暖宝宝发热（ΔH<0）和冰袋吸热（ΔH>0）都是典型例子。需注意：焓变是状态函数，仅与始末状态有关，与反应路径无关。实验室中可通过量热计直接测量，如中和反应实验测得 HCl+NaOH 的 ΔH ≈ -57.3 kJ/mol。

焓变与反应热的区别

反应热是反应过程中实际交换的热量，而焓变是恒压条件下的特定反应热（Qp）。例如：火箭燃料联氨（N₂H₄）燃烧时，若在敞口容器中测量（恒压）得到 ΔH = -622 kJ/mol，但在密闭弹式量热计中（恒容）测得 Qv = -617 kJ/mol，差值来自体系做功。关键区别在于：①焓变必定对应恒压条件；②反应热可能包含体积功。学科交叉案例：人体代谢葡萄糖（C₆H₁₂O₆ + 6O₂ → 6CO₂ + 6H₂O）的 ΔH = -2805 kJ/mol，但实际释放能量部分用于肌肉做功，不完全转化为热。

标准摩尔生成焓的应用

标准摩尔生成焓（ΔfH°）指在标准状态下，由稳定单质生成1摩尔化合物的焓变。例如：ΔfH°(H₂O,l) = -285.8 kJ/mol，表示 H₂(g) + ½O₂(g) → H₂O(l) 的能量变化。通过赫斯定律可计算反应焓变：ΔH° = ΣΔfH°(产物) - ΣΔfH°(反应物)。实战案例：计算铝热反应 2Al + Fe₂O₃ → Al₂O₃ + 2Fe 的 ΔH°，已知 ΔfH°(Al₂O₃) = -1675.7 kJ/mol，ΔfH°(Fe₂O₃) = -824.2 kJ/mol，得出 ΔH° = -851.5 kJ/mol，解释为何该反应能产生高温熔融铁。

键能与焓变的定量关系

化学反应本质是旧键断裂（吸热）和新键形成（放热）。例如：H₂ + Cl₂ → 2HCl 中，断裂 H-H 键（436 kJ/mol）和 Cl-Cl 键（243 kJ/mol）需吸热 679 kJ，形成 2 mol H-Cl 键（431 kJ/mol×2）放热 862 kJ，故 ΔH = -183 kJ/mol。典型错误是忽略系数：计算 N₂ + 3H₂ → 2NH₃ 时，需注意断裂 1 mol N≡N 键（945 kJ）和 3 mol H-H 键（436 kJ×3），形成 6 mol N-H 键（391 kJ×6）。实际工业合成氨 ΔH = -92 kJ/mol 印证该计算。

盖斯定律的运用技巧

盖斯定律指出：反应总焓变等于各分步焓变之和。解题关键：①合理设计反应路径；②利用已知方程进行代数运算。案例：已知 C + O₂ → CO₂ ΔH₁ = -393.5 kJ/mol，CO + ½O₂ → CO₂ ΔH₂ = -283.0 kJ/mol，求 C + ½O₂ → CO 的 ΔH₃。解法：将方程(1)减去方程(2)得 ΔH₃ = -110.5 kJ/mol。工业应用：通过 Fe₂O₃ + 3CO → 2Fe + 3CO₂（ΔH = -28 kJ/mol）与 C + O₂ → CO₂ 联立，可推导出炼铁高炉中焦炭（C）生成还原剂 CO 的热效应。

溶解热与稀释热的测量

溶解热指1摩尔溶质溶于大量溶剂时的焓变。例如：NaOH 固体溶于水 ΔH = -44.5 kJ/mol（放热），NH₄NO₃ 溶于水 ΔH = +25.7 kJ/mol（吸热）。稀释热是溶液进一步稀释的热效应，如浓硫酸稀释会剧烈放热。实验方法：使用保温杯式量热计，记录温度变化 ΔT，通过 Q = mcΔT 计算热量（c 为溶液比热容，约 4.18 J/g·℃）。注意：①需考虑量热计热容；②确保溶液足够稀以避免后续稀释热干扰。生活案例：运动饮料含电解质的设计需考虑溶解热对口感的影响。

燃烧热的工程应用

燃烧热指1摩尔物质完全燃烧的焓变，需指定产物状态。例如：正庚烷（C₇H₁₆）的燃烧热 ΔH = -4817 kJ/mol（生成液态水），而若生成气态水则为 -4784 kJ/mol。航空领域：比较航空煤油（C₁₂H₂₆，ΔH ≈ -7513 kJ/mol）与液氢（ΔH = -286 kJ/mol）的能量密度。环境评估：甲烷（ΔH = -890 kJ/mol）比煤炭（以 C 计，ΔH = -393.5 kJ/mol）更清洁，因单位能量产生的 CO₂ 更少。计算误区：未平衡方程会导致数值错误，如计算 C₂H₆ 燃烧热时需配平为 C₂H₆ + 3.5O₂ → 2CO₂ + 3H₂O。

熵变与焓变的协同分析

根据吉布斯自由能公式 ΔG = ΔH - TΔS，需同时考虑焓变和熵变。例如：CaCO₃ 分解（ΔH° = +178 kJ/mol，ΔS° = +160 J/mol·K）在高温下自发（ΔG < 0），而常温下 ΔH 主导则不发生。相变案例：冰融化为水（ΔH > 0，ΔS > 0），0℃ 时 ΔG = 0 达平衡。工业案例：哈伯法合成氨（ΔH < 0，ΔS < 0）需适当温度（约 400℃）平衡二者。常见错误：忽略熵变对反应方向的影响，如误认为所有放热反应（ΔH < 0）都自发。
