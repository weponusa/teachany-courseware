ABT

引入：为什么分开反应物，灯泡就能亮？

已经知道

氧化还原反应的本质是电子转移。锌比铜活泼，Zn 容易失电子，Cu²⁺容易得电子。

但是问题是

如果 Zn 和 Cu²⁺直接接触，电子在溶液界面转移，能量主要变成热，无法稳定驱动外电路。

因此要学

原电池把氧化与还原放到两个半电池中，让电子被迫走导线，化学能就转化为电能。

Worked Example

例题：写出 Zn-Cu 原电池的总反应

全支架

阳极氧化：Zn → Zn²⁺ + 2e⁻。阴极还原：Cu²⁺ + 2e⁻ → Cu。电子数相同，直接相加。

半支架

若 Fe | Fe²⁺ 与 Cu²⁺ | Cu 组成原电池，请先写出 Fe 的氧化半反应，再与 Cu²⁺ 的还原半反应相加。

独立完成

给定 Mg²⁺/Mg 与 Ag⁺/Ag 的标准电极电势，判断谁作阳极，并写出总反应。

Zn(s) + Cu²⁺(aq) → Zn²⁺(aq) + Cu(s)

核心模块 1

原电池把化学能转化为电能，必须形成闭合回路

自发氧化还原反应可设计成原电池：负极发生氧化失电子，正极发生还原得电子，电子经外电路从负极流向正极，离子在电解质中迁移以保持电中性。没有闭合回路就没有持续电流；盐桥（或离子通道）的作用是沟通内电路、平衡电荷。

例题拆解：锌铜原电池：Zn 为负极 Zn−2e⁻→Zn²⁺；Cu 为正极 Cu²⁺+2e⁻→Cu；电子外电路 Zn→Cu。

核心模块 3

电动势与电极反应式要把氧化、还原分开写清

总反应=负极氧化反应+正极还原反应。检查：得失电子数相等，原子与电荷守恒。盐桥中阳离子移向正极区、阴离子移向负极区，用于补偿电极区电荷变化。练习时先标负极/正极，再写半反应，最后合并，减少符号写反。

例题拆解：Zn|Zn²⁺||Cu²⁺|Cu 总反应：Zn+Cu²⁺→Zn²⁺+Cu。

Core Concept

核心概念：阳极氧化，阴极还原

阳极：氧化

Zn(s) → Zn²⁺(aq) + 2e⁻

锌片逐渐变薄，溶液中 Zn²⁺增多。这里是电子的来源。

阴极：还原

Cu²⁺(aq) + 2e⁻ → Cu(s)

铜片上析出铜，Cu²⁺浓度降低。这里是电子的去处。

方法与范例

方法：活泼金属为负、写半反应

比较金属活动性判断正负；负极写失电子，正极写得电子（可能是 H⁺、O₂、或电解质中的金属离子）。总反应即自发氧化还原反应。

范例：Fe-Cu 稀硫酸原电池：Fe 为负极 Fe−2e⁻=Fe²⁺，正极 2H⁺+2e⁻=H₂↑。

常见误区：常见误区是认为电子经溶液流动，或正负极判断只看金属位置不看活泼性。

Summary

小结：原电池不是容器组合，而是两条通道

回到开头：原电池把自发氧化还原反应拆成两个半反应，让电子走外电路、离子走盐桥。只要能同时说清“谁失电子、电子往哪走、离子如何补偿电荷”，你就真正理解了原电池。

阳极氧化阴极还原电子走导线离子走盐桥电势来自反应驱动力

核心模块 2

电极判断：看谁更容易失电子，不要只背金属活动性口诀

一般较活泼、更易被氧化的金属作负极；正极为氧化剂得电子的场所（可以是较不活泼金属或导电惰性电极）。写电极反应时要配平电荷与原子，并标明电极材料是否参与反应。电流方向与电子相反：外电路电流从正极流向负极。

例题拆解：镁铝酸性原电池中 Mg 更易失电子作负极；若两极都是惰性电极，则由溶液中氧化还原电对决定。
