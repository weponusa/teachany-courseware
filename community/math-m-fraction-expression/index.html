知识模块一：分式的概念与约分通分

▼
🧐 生活情境

用 x 升水平均分给 (x+3) 人，每人得 x/(x+3) 升。当 x=-3 时，分母为0，就没法分了！这就是为什么要限制分母不为0。

⚠️
分式有意义的条件：分母 ≠ 0
对分式 A/B，必须 B ≠ 0（A、B是整式，B含字母）
✂️ 分式的约分
约分原则：分子分母除以公因式（因式分解后消去公因式）
🔢 约分示例

约分 (x²-4)/(x²-x-2)

  • 分解分子：x²-4 = (x+2)(x-2)
  • 分解分母：x²-x-2 = (x-2)(x+1)
  • 消公因式 (x-2)：= (x+2)/(x+1)
原式 = (x+2)(x-2) / [(x-2)(x+1)] = (x+2)/(x+1) （x≠2, x≠-1）
🔢 通分
通分示例：将 1/(x+1) 和 2/(x-1) 通分
  • 找最简公分母（LCD）= (x+1)(x-1)
  • 第一个：1/(x+1) = (x-1)/[(x+1)(x-1)]
  • 第二个：2/(x-1) = 2(x+1)/[(x+1)(x-1)]
⚠️ 约分常见错误

错误：(x²+4)/(x+4) = x （直接消去4）

正确：分子 x²+4 和分母 x+4 无公因式，无法约分！

只有公因式（乘积关系）才能约分，加减关系的项不能消！

知识模块二：分式的四则运算

▼
🧐 类比分数运算

分式运算与分数完全类似：1/2 + 1/3 = 3/6 + 2/6 = 5/6。把数字换成代数式，道理不变！先通分，再运算。

运算规则示例
乘法分子×分子，分母×分母(a/b)×(c/d) = ac/bd
除法乘以倒数(a/b)÷(c/d) = (a/b)×(d/c) = ad/bc
同分母加减分母不变，分子加减a/c ± b/c = (a±b)/c
异分母加减先通分，再加减1/(x+1) + 1/(x-1) → 通分
🔢 加减运算示例

计算：1/(x+1) - 1/(x-1)

  • 公分母 = (x+1)(x-1) = x²-1
  • 通分：(x-1)/(x²-1) - (x+1)/(x²-1)
  • 分子相减：(x-1)-(x+1) = -2
  • 结果：-2/(x²-1)
= -2 / (x²-1) （x≠1, x≠-1）
🔢 乘除运算示例

计算：(x²-1)/(x+2) ÷ (x-1)/(x²-4)

  • 除法变乘法，乘以第二个分式的倒数
  • = (x²-1)/(x+2) × (x²-4)/(x-1)
  • 因式分解：x²-1=(x+1)(x-1)，x²-4=(x+2)(x-2)
  • 约分消公因式
= (x+1)(x-1)(x+2)(x-2) / [(x+2)(x-1)] = (x+1)(x-2)
⚠️ 分式加减错误

错误：1/x + 1/y = 2/(x+y)

正确：1/x + 1/y = y/(xy) + x/(xy) = (x+y)/(xy)

分母相加≠新分母！必须通分！

知识模块三：分式方程与增根

▼
🧐 为什么要验根？

解分式方程时，我们"去分母"——但如果某个解让分母=0，那它其实不合法！这样的"假解"叫增根，必须舍去。

解分式方程步骤：
①确定公分母 → ②两边乘公分母（去分母）→ ③解整式方程 → ④验根（代回检验分母是否为0）
🔢 完整示例：解方程

解：1/(x-1) + 2 = 3/(x-1)

  • 公分母 = (x-1)
  • 两边乘(x-1)：1 + 2(x-1) = 3
  • 展开：1 + 2x - 2 = 3 → 2x - 1 = 3 → x = 2
  • 验根：x=2 时，x-1=1≠0 ✅，分母不为0，x=2是合法解
∴ x = 2
⚠️ 含增根的示例

解：x/(x-2) = 2/(x-2) + 1

  • 两边乘(x-2)：x = 2 + (x-2) = x
  • 整理：0 = 0，说明原本是恒等式？
  • 实际上若直接解得 x=2，代入验证：x-2=0，分母为0 ❌
  • x=2 是增根，方程无解
练习：解方程 3/x = 6/（x+1），x = ?
练习：方程 1/(x-3) = 2/(x²-9) 的解？（x²-9=(x-3)(x+3)）

知识精讲

分式

分母中含有字母的式子叫分式，分母不能为零。分式的基本性质：分子分母同乘（或同除）一个不为零的整式，分式的值不变。约分要先因式分解，通分要找最简公分母。

方法与范例

方法：先分解再约分，随时标条件

化简时把分子分母都分解因式，约去公因式，并写明使分母不为零的取值条件。加减时通分，乘除时把除法化为乘倒数。

范例：(x² − 1)/(x + 1) = (x+1)(x−1)/(x+1) = x − 1（x ≠ −1）。

常见误区：常见误区是约分时“约项不约因式”，或化简后忘记标注分母不为零的条件。

📖 分数表达式

And：学生已掌握分数的基本概念

But：但面对复杂表达式时容易混淆运算顺序

Therefore：本模块帮助学生理清分数运算的优先级

分数表达式是由分数和运算符号组成的式子。计算时要遵循先乘除后加减的顺序。例如：计算 1/2 + 3/4 × 2/3 时，先算乘法部分 3/4 × 2/3 = 6/12 = 1/2，再加上 1/2，最终结果是1。

🌍 就像做蛋糕时，要先混合面粉和糖（乘法），再加鸡蛋（加法），顺序错了会影响成品。

🏋️ 即练

计算：2/3 - 1/4 × 4/5

📖 带括号运算

And：学生会基础分数运算

But：遇到括号时不确定何时需要改变符号

Therefore：掌握括号对分数表达式的影响

括号会改变运算顺序，分数前的负号要特别注意。例如：(1/2 - 1/3) × 2 = (3/6 - 2/6) × 2 = 1/6 × 2 = 1/3。如果括号前有负号，如 -(1/2 + 1/4) = -3/4，相当于给括号内每一项变号。

🌍 就像超市满减活动，括号就像优惠组合，负号就像'不参与活动'的标签。

🏋️ 即练

计算：-(2/5 + 1/10) ÷ 1/2

📖 连分数化简

And：学生能计算两步分数运算

But：面对多层分数嵌套时无从下手

Therefore：学会用倒数法简化复杂分数

连分数是指分子或分母仍是分数的表达式。化简时要找到主分数线，把除号变乘号并取倒数。例如：(1/2)/(3/4) = 1/2 × 4/3 = 2/3。再复杂的如 [(1+1/2)/3]/(1/4) 可以分层计算。

🌍 就像俄罗斯套娃，要一层层打开，最大的套娃（主分数线）决定打开顺序。

🏋️ 即练

化简：(2/3)/(4/9)

📖 实际应用题

And：学生已掌握分数计算技巧

But：遇到实际问题时不会建立表达式

Therefore：培养将生活问题转化为分数模型的能力

应用题的关键是找出'整体1'。例如：小明喝掉水的1/3，又倒入200ml后水量是原来的5/6。设原水量为x，建立方程：(1-1/3)x + 200 = 5/6x，解得x=1200ml。注意单位要统一。

🌍 就像给手机充电，消耗的电量（分数）和充电量（具体数值）要一起考虑。
