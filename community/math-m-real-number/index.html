📖 模块一：无理数的发现
📖 AND（背景）

古希腊数学家毕达哥拉斯相信"万物皆有理数"。他们认为，任何两段线的长度之比都可以用整数之比表示。

⚡ BUT（冲突）

一个正方形，边长为1，对角线是多少？用勾股定理：对角线² = 1² + 1² = 2，所以对角线 = √2。但是 √2 = ? 它不等于任何分数！

💡 THEREFORE（解决）

√2 是一种新类型的数——无理数。它的小数展开是无限且不循环的：√2 ≈ 1.41421356…

📌 有理数与无理数的本质区别

有理数：可以写成分数 p/q（整数比）→ 小数展开是有限小数或无限循环小数

无理数：不能写成分数形式 → 小数展开是无限不循环小数

📖 模块三：实数的运算与大小比较
💡 THEREFORE（解决）

实数的运算法则和有理数相同（加减乘除），但比较大小时，对于含根号的数，需要用估算或化简的方法。

📌 平方根和算术平方根

  • 算术平方根：非负数a的非负平方根，记作 √a（a ≥ 0）
  • 平方根：a²= b，则a是b的平方根（有±两个，b > 0时）
  • √a × √a = a（a ≥ 0）
  • √(a²) = |a|（注意绝对值！）
⚠️ 反例镜——√(a²)的陷阱

√(a²) ≠ a！正确结论是 √(a²) = |a|

当a = 3时：√(3²) = √9 = 3 = |3| ✓
当a = -3时：√((-3)²) = √9 = 3 = |-3| ✓
不能写成√((-3)²) = -3（错误！√结果必须非负）

📌 实数大小比较

  • 利用估算：√3 ≈ 1.732，则 √3 与 1.8 比较：1.732 < 1.8，所以 √3 < 1.8
  • 两边平方（两数都是正数时）：比较 √5 和 2，都是正数，5 vs 4，5>4，所以 √5 > 2

科学记数法的应用

科学记数法用a×10ⁿ（1≤a<10，n为整数）表示极大或极小数。例如光速3×10⁸米/秒，新冠病毒直径约1×10⁻⁷米。在化学中，阿伏伽德罗常数6.02×10²³/mol表示1摩尔物质的粒子数。天文学中，地球到太阳距离1.496×10⁸公里。当学生计算银河系恒星数量（约10¹¹颗）时，用科学记数法比写100,000,000,000更高效。手机处理器7纳米工艺即7×10⁻⁹米，这种表达在纳米技术中至关重要。

知识精讲

实数

实数由有理数和无理数组成。无理数是无限不循环小数，如 √2、π。算术平方根非负，立方根与被开方数同号。实数与数轴上的点一一对应，因此可以在数轴上比较任意两个实数的大小。

方法与范例

方法：先判有理无理，再估值定位

判断无理数看能否写成两整数之比；估算 √n 时找相邻完全平方数夹逼，如 4＜5＜9 得 2＜√5＜3。

范例：√16 + ∛(−27) = 4 + (−3) = 1，注意立方根可以为负。

常见误区：常见误区是认为带根号的一定是无理数（如 √4=2 是有理数），或以为负数没有立方根。

Therefore：引入无理数完善数系

像√2这样无限不循环的小数叫无理数，它不能写成两个整数之比。比如计算边长为1的正方形对角线：根据勾股定理得√(1²+1²)=√2≈1.414...这个数永远算不到尽头且不循环，我们用量化的例子说明它确实存在。

🌍 装修时测量瓷砖对角线，发现40cm×40cm的瓷砖对角线约56.57cm（40√2），这个√2就是无理数的实际应用。
