📖 模块一：一元一次不等式的概念

And（对比方程）

你已经学会解方程 2x + 3 = 7，找到唯一的 x 值。但是，如果条件是 "2x + 3 > 7" 呢？x 不是唯一一个值，而是一大片！

But（方程 vs 不等式）

⚖️ 方程

2x + 3 = 7

解：x = 2（唯一值）

数轴上：一个点

📏 不等式

2x + 3 > 7

解：x > 2（无穷多）

数轴上：一条射线

Therefore（定义）

一元一次不等式：只含一个未知数，未知数最高次数为1，且含有不等号的不等式。

标准形式：ax + b > c（或 <、≤、≥，其中 a ≠ 0）

其解集是满足不等式的所有 x 的值的集合，通常是一条射线（无穷多个解）。

🔭 数轴表示法（可视化镜）

x > 2 ← ●○——————————→ 空心圆，向右箭头
x ≥ 2 ← ●●——————————→ 实心圆，向右箭头
x < 2 ←——————————○●→ 空心圆，向左箭头
x ≤ 2 ←——————————●●→ 实心圆，向左箭头

口诀：有等号（≤或≥）→ 实心圆；无等号（<或>）→ 空心圆

⚡ 练习：x ≤ -1 在数轴上，端点 -1 应该用什么圆？箭头向哪边？
🧮 模块二：解一元一次不等式（步骤详解）

And（类比方程的解法）

解不等式的步骤和解方程几乎完全一样——移项、合并、系数化1。唯一的区别是：乘除负数时不等号翻转！

Therefore（完整解题流程）

例1（系数为正）：解 2x - 4 > 6

移项：2x > 6 + 4 → 2x > 10
系数化1（除以正数2，不翻转）：x > 5
数轴表示：5右侧，空心圆，向右箭头

例2（系数为负）：解 -3x + 6 > 15

移项：-3x > 15 - 6 → -3x > 9
除以 -3（负数！翻转！）：x < -3
数轴表示：-3左侧，空心圆，向左箭头

🔭 错误防雷镜

⚠️ 最常见错误类型：

错误做法原因正确做法
-2x > 8 → x > -4忘记翻转x < -4 ✓
x-3>5 → x>2移项符号错x > 8 ✓
2x>-6 → x>-6漏除以2x > -3 ✓

🌍 模块三：一元一次不等式应用

And（应用题类型）

不等式应用题的关键是找到"不等量关系"，常见于：最多/最少问题、满足条件问题、行程问题等。

Therefore（解题示例）

例：某工厂计划生产零件，第一天生产了200个，此后每天生产150个。问至少需要几天才能完成1000个的订单？

设未知数：设还需要 x 天（不含第一天）
建立不等式：200 + 150x ≥ 1000
解不等式：150x ≥ 800 → x ≥ 800÷150 ≈ 5.33
取整数：x 至少为 6（天数必须是整数）
解答：共需 1+6 = 7 天（含第一天）

🔭 注意：整数约束

在实际应用中，x 常常要求是整数（天数、人数、个数等）。

若解出 x > 5.33，且 x 为正整数，则 x ≥ 6（向上取整）

若解出 x < 7.8，且 x 为正整数，则 x ≤ 7（向下取整）

不等式的基本概念

不等式是数学中表示两个量大小关系的表达式，用符号“>”“<”“≥”“≤”连接。例如，3x + 2 > 8 表示3x加2的结果大于8。与等式不同，不等式描述的是一个范围而非固定值。生活中，比如购物预算“花费不超过500元”可表示为x ≤ 500。解不等式时，解集通常是一个区间，如x > 2表示所有大于2的数。注意：不等式两边同时乘以或除以负数时，不等号方向需反转，例如-2x < 6的解是x > -3。

一元一次不等式的标准形式

一元一次不等式的标准形式为ax + b > 0（或<, ≥, ≤），其中a≠0。例如：2x - 5 ≤ 0。关键步骤是化为ax > -b的形式，再通过系数a的正负决定解集方向。实例：解不等式3(x - 1) + 2 < 5x，先展开得3x - 3 + 2 < 5x，合并同类项后为-2x < 1，最终解为x > -0.5（注意除负数时符号反转）。学科应用如物理学中速度限制问题：汽车速度v需满足v ≤ 120km/h。

数轴表示解集

用数轴直观展示不等式解集时，需注意空心圈（>或<）与实心圈（≥或≤）的区别。例如x ≥ 3在数轴上为实心圈覆盖3并向右延伸；-1 < x ≤ 4则用空心圈标-1、实心圈标4，中间连线段。生活案例：温度控制要求t > 20℃且t ≤ 25℃时，数轴表现为(20,25]区间。易错点是端点取舍，如“不超过”对应“≤”。练习：将x < -2或x ≥ 1的解集画在数轴上，注意使用不同符号表示开闭区间。

含分母不等式的解法

解如(2x - 1)/3 > 5的不等式时，首先消分母：两边同乘3得2x - 1 > 15（注意分母为正时不改符号）。继续解得x > 8。若分母含未知数如1/(x - 2) < 3，需分情况讨论分母正负，并注意x≠2的隐含条件。典型错误是忽略乘负数时的符号反转，例如解(x + 4)/(-2) ≥ 1时，正确步骤为x + 4 ≤ -2（乘-2反转符号），最终解为x ≤ -6。应用场景包括化学溶液浓度计算：c/(v + 5) > 0.1。

复合不等式与区间表示

复合不等式如-3 ≤ 2x + 1 < 5需拆解为两个部分：-3 ≤ 2x + 1和2x + 1 < 5，分别解得x ≥ -2和x < 2，最终解集为[-2,2)。区间表示中，圆括号表示不包含端点，方括号表示包含。例如“身高h在1.5米到1.8米之间”表示为1.5 ≤ h ≤ 1.8或[1.5,1.8]。易混淆的是“且”与“或”型复合不等式：“x < -1或x > 2”需用数轴上的两段分离区域表示，而“-1 < x < 2”是单一连续区间。

实际应用问题建模

将实际问题转化为不等式时，需抓住关键词：“至少”“最多”“不超过”分别对应≥、≤、≤。例题：电影院儿童票至少买3张才能享受团体优惠，设购买数为x，则x ≥ 3；若预算200元，票价40元，最多可买x ≤ 200/40即x ≤ 5张。综合问题如“购买笔记本和笔总价不超过100元，笔记本每本15元，笔每支5元，至少买2本笔记本”可建立不等式组：15x + 5y ≤ 100且x ≥ 2，其中x、y为整数。

不等式与方程解的对比

对比方程3x + 2 = 8（解唯一：x = 2）与不等式3x + 2 > 8（解集无限：x > 2），强调解的本质差异。关键区别在于：1）不等式解是范围；2）变形时需注意符号方向。例如解(x - 1)/2 = 3得x = 7，而(x - 1)/2 > 3得x > 7。特殊案例：|2x - 1| = 3有x = 2或x = -1两个解，而|2x - 1| < 3的解集为-1 < x < 2。学科联系如经济学中盈亏平衡点（方程）与盈利区间（不等式）的分析。

含绝对值不等式的解法

解|ax + b| < c（c > 0）型不等式时，转化为-c < ax + b < c的复合不等式。例如|2x - 3| ≤ 5等价于-5 ≤ 2x - 3 ≤ 5，解得-1 ≤ x ≤ 4。对于|ax + b| > c的情况，则拆解为ax + b < -c或ax + b > c。实例：解|x + 2| > 3得x < -5或x > 1。注意绝对值的几何意义是数轴上距离，因此|x - a| < b表示与a的距离小于b的点。应用案例如零件尺寸误差范围：|d - 10mm| ≤ 0.2mm。

不等式在生活中的应用

一元一次不等式在生活中有广泛的应用。例如，假设你计划购买一些文具，预算不超过50元。笔记本每本5元，钢笔每支10元。设购买笔记本的数量为x，钢笔的数量为y，那么可以列出不等式5x + 10y ≤ 50。这个不等式可以帮助你确定在预算内可以购买多少本笔记本和钢笔。另一个例子是时间管理。假设你每天有最多3小时的时间用于学习和娱乐。学习时间为x小时，娱乐时间为y小时，那么不等式x + y ≤ 3可以帮助你合理安排时间，确保学习和娱乐的平衡。

不等式与方程的区别

一元一次不等式与一元一次方程在形式上相似，但在解法和意义上有所不同。方程表示两个表达式相等，而不等式表示两个表达式之间存在大小关系。例如，解方程2x + 3 = 7，我们得到x = 2。而解不等式2x + 3 < 7，我们得到x < 2。这意味着x可以是任何小于2的数，而不是一个具体的值。在图形表示上，方程的解是直线上的一个点，而不等式的解是直线一侧的区域。例如，不等式y > 2x + 1表示在直角坐标系中，所有位于直线y = 2x + 1上方的点都是解。理解这些区别有助于更好地掌握不等式的应用和解法。

💡 错因诊断

常见错因：1）忽略乘除负数时的符号反转，如解-2x > 6误写为x > -3；2）混淆“且”“或”型复合不等式的区间表示。诊断方法：通过数轴验证解集是否合理，检查每一步的符号处理。误区警示：绝对值不等式未考虑两种情形，如|3x + 1| ≥ 5未拆解为3x + 1 ≤ -5或3x + 1 ≥ 5。
