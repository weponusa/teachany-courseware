❓引入：铝制易拉罐的秘密

生活中铝无处不在：易拉罐、铝箔纸、飞机机身、门窗框架。铝的密度只有铁的三分之一，却拥有不错的强度，而且表面总有一层亮闪闪的薄膜。

但有一个奇怪的现象：铝制易拉罐不能长时间装酸性饮料（如碳酸饮料）或碱性液体。 为什么？

更奇怪的是，铝既能与盐酸反应放出氢气，也能与氢氧化钠溶液反应放出氢气。大多数金属只与酸反应，铝为什么"两边都行"？

这就是我们今天要探究的核心问题。

⚛️核心概念一：铝单质的性质

1. 物理性质

银白色金属，密度 2.70 g/cm³（约为铁的 1/3），熔点 660°C，具有良好的导电性、导热性和延展性。

2. 化学性质——表面氧化膜的保护作用

铝是活泼金属，但常温下与空气接触会迅速形成一层致密的 Al₂O₃ 氧化膜（厚度约 4 nm），阻止内部铝继续被氧化。这层膜是铝制品耐腐蚀的关键。

3. 与酸反应

与盐酸反应 2Al + 6HCl → 2AlCl₃ + 3H₂↑

现象：产生大量无色气泡（氢气）。本质是 Al 失去电子，H⁺ 得到电子。

4. 与强碱反应

与氢氧化钠反应 2Al + 2NaOH + 2H₂O → 2NaAlO₂ + 3H₂↑

现象：产生无色气泡。反应分两步：Al 先与水反应生成 Al(OH)₃ 和 H₂，生成的 Al(OH)₃ 再与 NaOH 反应生成可溶的 NaAlO₂，从而使反应持续进行。

🧪核心概念二：氧化铝的两性

氧化铝（Al₂O₃）是一种典型的两性氧化物：既能与酸反应生成盐和水，也能与强碱反应生成盐和水。

与酸反应（表现碱性）
Al₂O₃ + 6HCl → 2AlCl₃ + 3H₂O
与碱反应（表现酸性）
Al₂O₃ + 2NaOH → 2NaAlO₂ + H₂O

由于 Al₂O₃ 具有两性，铝制品在酸性或碱性环境中都会被腐蚀。这就是铝制易拉罐不宜长时间装碳酸饮料或碱性清洁剂的原因。

🔬核心概念三：氢氧化铝的两性 · 虚拟实验

氢氧化铝 Al(OH)₃ 是一种白色胶状沉淀，同样具有两性。下面的虚拟实验可以帮助你直观理解：向含有 Al³⁺ 的溶液中逐滴加入试剂，观察沉淀的生成与溶解。

实验原理与结论

制备 Al(OH)₃：Al³⁺ + 3NH₃·H₂O → Al(OH)₃↓ + 3NH₄⁺（用弱碱氨水，避免过量强碱溶解沉淀）

与酸反应：Al(OH)₃ + 3HCl → AlCl₃ + 3H₂O

与强碱反应：Al(OH)₃ + NaOH → NaAlO₂ + 2H₂O

结论：Al(OH)₃ 既能与酸反应，也能与强碱反应，是典型的两性氢氧化物。

🔥核心概念四：铝热反应

铝热反应是铝在高温下还原金属氧化物的反应，放出大量的热，温度可达 2500°C 以上。

铝热反应（以氧化铁为例） 2Al + Fe₂O₃ —高温→ 2Fe + Al₂O₃ + 大量热

该反应需要高温引发，通常用镁条和氯酸钾作为引燃剂。反应一旦开始，放出的热量足以维持反应继续进行。

工业应用
  • 焊接钢轨（现场修复铁路）
  • 冶炼难熔金属（如钒、铬、锰）
  • 火箭固体燃料助推
反应特点
  • 放热剧烈，温度极高
  • 产物铁呈熔融态
  • 需在安全环境下操作
  • 铝作为还原剂，体现还原性

✏️例题与演练

例题 1 写出铝与氢氧化钠溶液反应的离子方程式，并标出电子转移方向和数目。

答案：2Al + 2OH⁻ + 2H₂O → 2AlO₂⁻ + 3H₂↑
电子转移：Al 失去 6e⁻（0 → +3），H⁺ 得到 6e⁻（+1 → 0）

例题 2 为什么制备 Al(OH)₃ 时常用氨水而不用 NaOH 溶液？

答案：因为 Al(OH)₃ 具有两性，能与过量强碱（NaOH）反应生成可溶的 NaAlO₂，导致沉淀溶解。氨水是弱碱，即使过量也不会溶解 Al(OH)₃ 沉淀。
💡互动练习

判断以下说法是否正确：

  1. 铝在空气中不能燃烧，因为表面有氧化膜保护。（√ 正确）
  2. Al₂O₃ 既能与盐酸反应，也能与 NaOH 反应，所以它是碱性氧化物。（× 错误，是两性氧化物）
  3. 铝热反应中，铝作氧化剂，Fe₂O₃ 作还原剂。（× 错误，铝是还原剂）
  4. 向 AlCl₃ 溶液中逐滴加入 NaOH 溶液，先产生白色沉淀，后沉淀溶解。（√ 正确）
📝课堂小测

1. 下列关于铝的说法正确的是（ ）

  • A铝不能与碱反应
  • B铝表面有致密氧化膜，具有抗腐蚀性
  • C铝热反应中铝是氧化剂
  • DAl(OH)₃ 只能与酸反应
铝表面形成致密 Al₂O₃ 膜，阻止进一步氧化，这是铝抗腐蚀的原因。铝能与强碱反应；铝热反应中铝失电子作还原剂；Al(OH)₃ 是两性氢氧化物。

2. 实验室制备 Al(OH)₃ 的最佳试剂是（ ）

  • A过量 NaOH 溶液
  • B过量盐酸
  • C适量氨水
  • D过量稀硫酸
氨水是弱碱，能使 Al³⁺ 沉淀为 Al(OH)₃，且过量不会溶解沉淀。NaOH 过量会使沉淀溶解生成 NaAlO₂。

3. 铝热反应可用于焊接钢轨，其原理是（ ）

  • A反应放出大量热，使铁熔化流入缝隙
  • B反应生成铝蒸气填充缝隙
  • C反应产生高压将钢轨压合
  • D铝比铁活泼，置换反应自动进行
铝热反应放出大量热（约 2500°C），生成的铁呈熔融态，可流入钢轨缝隙冷却后形成牢固焊缝。
📋总结

铝单质

活泼金属，表面有致密 Al₂O₃ 保护膜。既能与酸反应，也能与强碱反应放出 H₂。

两性化合物

Al₂O₃ 和 Al(OH)₃ 都是两性物质：既能与酸反应，也能与强碱反应。

铝热反应

高温下放热反应，用于焊接钢轨和冶炼难熔金属。铝作还原剂。

核心线索：铝的"两面性"源于 Al³⁺ 处于金属与非金属的交界，使其化合物具有独特的两性特征。

铝的物理性质

铝是一种银白色的轻金属，密度约为2.7 g/cm³，仅为铁的1/3。它具有优良的延展性和导电性，导电率约为铜的60%。生活中常见的铝制品包括易拉罐、铝合金门窗等。例如，飞机机身大量使用铝合金，既减轻重量又保持强度。铝的熔点约为660°C，沸点约2467°C。实验室中可用铝箔包裹食物进行加热，因其导热快且耐高温。值得注意的是，纯铝较软，通常通过添加其他元素（如铜、镁）制成合金以提高硬度。

铝的化学性质

铝是活泼金属，在常温下能与氧气反应生成致密的氧化铝保护膜（4Al + 3O₂ → 2Al₂O₃），这使其具有抗腐蚀性。例如，铝锅表面自然形成的氧化膜可防止进一步锈蚀。铝能与酸反应放出氢气（2Al + 6HCl → 2AlCl₃ + 3H₂↑），实验室可用此反应制取少量氢气。高温下铝还能与某些金属氧化物发生铝热反应（如2Al + Fe₂O₃ → Al₂O₃ + 2Fe），工业上用于焊接铁轨。需要注意的是，铝在浓硝酸中会钝化，这是因其表面形成了更致密的氧化膜。

氧化铝的两性特性

氧化铝（Al₂O₃）是典型的两性氧化物，既能与酸反应生成铝盐（Al₂O₃ + 6HCl → 2AlCl₃ + 3H₂O），又能与强碱反应生成偏铝酸盐（Al₂O₃ + 2NaOH → 2NaAlO₂ + H₂O）。例如，工业上常用氢氧化钠溶液溶解铝土矿提取氧化铝。自然界中的刚玉就是纯净的α-Al₂O₃，莫氏硬度达9，用作磨料和红宝石基材。实验演示：将氧化铝粉末分别加入盐酸和氢氧化钠溶液，观察溶解现象。特别提醒：氧化铝不溶于水，普通条件下也不与弱酸弱碱反应。

氢氧化铝的两性

氢氧化铝（Al(OH)₃）是白色胶状沉淀，具有两性：与酸反应生成铝盐（Al(OH)₃ + 3HCl → AlCl₃ + 3H₂O），与强碱反应生成偏铝酸盐（Al(OH)₃ + NaOH → NaAlO₂ + 2H₂O）。胃药"氢氧化铝片"就是利用其中和胃酸的作用。实验室制备方法：向铝盐溶液滴加氨水（AlCl₃ + 3NH₃·H₂O → Al(OH)₃↓ + 3NH₄Cl）。有趣现象：新制氢氧化铝能溶于过量强碱，但久置后转化为更难溶的α-Al(OH)₃则不再溶解。医疗上还利用其吸附性制作止泻剂。

铝盐的水解反应

铝盐（如AlCl₃）在水中会发生强烈水解：Al³⁺ + 3H₂O ⇌ Al(OH)₃ + 3H⁺，使溶液呈酸性。例如，明矾（KAl(SO₄)₂·12H₂O）净水就是利用水解产生的氢氧化铝胶体吸附杂质。实验现象：氯化铝溶液加热后产生白色浑浊（水解加剧）。特别注意：配制铝盐溶液时应加入少量相应酸抑制水解。生活应用：含铝止汗剂通过水解产生的氢氧化铝堵塞汗腺。工业上电解铝时需要先溶解氧化铝于熔融冰晶石，正是因为铝盐在水溶液中无法稳定存在。

偏铝酸盐的性质

偏铝酸盐（如NaAlO₂）是铝在强碱中的存在形式，其水溶液呈强碱性（AlO₂⁻ + 2H₂O ⇌ Al(OH)₃ + OH⁻）。向偏铝酸钠溶液通入CO₂可重新生成氢氧化铝沉淀（2NaAlO₂ + CO₂ + 3H₂O → 2Al(OH)₃↓ + Na₂CO₃），这是工业提铝的重要步骤。实验演示：向偏铝酸钠溶液逐滴加入盐酸，先产生沉淀后溶解，体现Al(OH)₃的两性。注意区分：偏铝酸根在过量酸中转化为Al³⁺（AlO₂⁻ + 4H⁺ → Al³⁺ + 2H₂O），而在适量酸中生成Al(OH)₃。

铝的冶炼方法

工业上通过霍尔-埃鲁法电解氧化铝生产铝：将Al₂O₃溶解于熔融冰晶石（Na₃AlF₆）中，在950°C下电解（2Al₂O₃ → 4Al + 3O₂↑）。阳极使用碳棒，反应中碳会消耗（C + O₂ → CO₂）。每生产1吨铝需消耗约1.9吨氧化铝和0.5吨碳电极。环保问题：该过程产生大量CO₂和氟化物废气。现代改进：采用惰性阳极减少碳排放。课前可展示铝锭实物，解释其表面有时有灰色是因冷却时表面氧化。我国铝产量居世界首位，主要分布在山东、新疆等地。

铝的重要化合物应用

①明矾（KAl(SO₄)₂·12H₂O）：净水剂、止血剂，利用其水解产生的Al(OH)₃胶体；②硫酸铝：造纸施胶剂，使纤维结合紧密；③氢氧化铝：阻燃添加剂，受热分解吸热（2Al(OH)₃ → Al₂O₃ + 3H₂O）；④铝酸钙水泥：快干耐高温，用于耐火材料；⑤人造刚玉：制成砂轮、手表轴承。创新应用：纳米氧化铝用于LED基板、锂电隔膜。注意区分：食品级氢氧化铝（抗结剂）与工业级的纯度要求不同。实验展示明矾净水过程，观察絮状沉淀的形成。

💡 错因诊断

错因：学生常误认为铝完全不锈蚀。误区：忽视表面氧化膜的保护作用。诊断：通过对比打磨前后的铝条在潮湿环境中的变化实验，直观展示氧化膜功能。另一个常见误区是混淆Al(OH)₃与Al₂O₃的溶解性，需强调前者能溶于强碱而后者不溶于水。
