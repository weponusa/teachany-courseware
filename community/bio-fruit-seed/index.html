🍎 果实和种子的形成

揭开双受精的奥秘——花如何变成果实，胚珠如何发育成种子

📚 核心知识讲解

一、传粉与花粉管

花粉从雄蕊（花粉囊）传到雌蕊（柱头）上的过程叫传粉。

花粉落在柱头上后：花粉萌发 → 长出花粉管 → 花粉管穿过花柱、子房壁 → 进入胚珠（经珠孔）→ 释放两个精子

二、双受精（被子植物特有）

花粉管中的两个精子进入胚珠后：

  • 精子① + 卵细胞 → 受精卵（→ 发育为胚）
  • 精子② + 极核（2个） → 受精极核（→ 发育为胚乳）

这种两个精子同时完成两次受精的现象叫双受精，是被子植物特有的。

1. 双受精是指：
A. 一粒花粉与两个卵细胞受精
B. 两粒花粉分别与两个卵细胞受精
C. 两个精子，一个与卵细胞融合，一个与极核融合
D. 一个精子与两个极核先后融合
✅ C正确！双受精是被子植物特有的：精子①+卵细胞→受精卵（发育为胚）；精子②+两个极核→受精极核（发育为胚乳）。两次受精同时完成。
2. 桃子的果肉（果皮）是由什么发育而来的？
A. 花瓣
B. 胚珠
C. 子房壁
D. 花萼
✅ C正确！子房壁发育为果皮（桃子果肉就是果皮）。子房整体发育为果实，胚珠（桃核里的种子）发育为种子。注意：桃核外面的硬壳也是果皮的一部分（内果皮）。
3. 一朵花中有5个胚珠，受精后最多能发育成多少粒种子？
A. 1粒
B. 3粒
C. 5粒
D. 10粒
✅ C正确！每个胚珠受精后发育为1粒种子。5个胚珠全部受精，最多发育为5粒种子。整个子房发育为含5粒种子的果实（如豌豆荚）。
4. 一颗桃子里我们吃到的"果肉"是由花的哪部分发育而来的？
A. 胚珠
B. 子房壁
C. 受精卵
D. 花托
✅ B正确！果实的果皮由子房壁发育而来，桃子的果肉就是果皮（中果皮），桃核硬壳是内果皮；胚珠才发育为种子。所以"吃桃子"吃的其实是膨大的子房壁。

🧠 记忆锚点

类比：果实像妈妈的子宫，种子就是里面的宝宝

为什么一朵花能变成一颗果实？（深入剖析）

传粉受精之后，子房并不是一个静止的结构——它会"长大变身"。这背后是激素信号在指挥：受精完成后，子房合成生长素等激素，启动发育程序。

🧩 一一对应关系：子房壁 → 果皮；胚珠 → 种子；受精卵 → 胚；受精极核 → 胚乳。整个子房膨大发育为果实。

🔑 常见误区：桃子的"果肉"其实是果皮（由子房壁发育），桃核的硬壳也是果皮的一部分（内果皮），核里的"仁"才是种子。草莓表面那些小颗粒，每一颗才是一枚真正的果实。

🌍 演化意义：果实包被并保护种子，还能借动物取食把种子带到远处，这是植物繁衍的重要策略。

📋 本课小结

传粉与花粉管

  • 花粉→柱头
  • 花粉管穿过花柱
  • 进入胚珠释放精子

双受精

  • 精子①+卵细胞→受精卵
  • 精子②+极核→受精极核
  • 被子植物特有

发育对应

  • 子房壁→果皮
  • 胚珠→种子
  • 受精卵→胚

整体关系

  • 子房→果实
  • 受精极核→胚乳
  • 花→凋落

🧠 核心对应关系

子房壁 → 果皮  |  胚珠 → 种子  |  子房 → 果实

受精卵 → 胚  |  受精极核 → 胚乳

⭐ 双受精 = 被子植物特有，两次融合同时进行
