📖 模块一：认识分式方程

And（问题引入）

🚗 小李开车从A到B，速度为 v km/h，距离60km，需要 60/v 小时。若速度增加20 km/h，时间减少1小时，建立方程：

60/(v+20) = 60/v - 1

注意分母中含有未知数 v！这就是分式方程。

But（与整式方程的区别）

类型特征例子
整式方程分母不含未知数2x + 3 = 7
分式方程分母含未知数1/x + 2 = 3/x

Therefore（核心挑战）

分式方程的分母不能为零！这是后面产生增根问题的根源。解题时必须检验解是否使原方程的分母为零。

⚙️ 模块二：解分式方程（去分母法）

And（核心思路）

分式方程难以直接求解，但如果两边同乘以最简公分母，就能把分式方程转化为整式方程来解！

Therefore（解题四步法）

例题：解 1/(x-2) + 1 = 3/(x-2)

找最简公分母（LCD）：分母为 (x-2)，LCD = x-2
两边乘以LCD，去分母：
(x-2) × [1/(x-2) + 1] = (x-2) × [3/(x-2)]
1 + (x-2) = 3
解整式方程：x - 1 = 3 → x = 4
验根（⚠️ 必须做！）：将 x=4 代入分母 (x-2)=2 ≠ 0
✓ 有效，x=4 是原方程的解
⚡ 解 2/x + 1 = 5/x，x = ？
⚠️ 模块三：增根问题（分式方程的特殊挑战）

And（什么是增根）

去分母后得到的整式方程的解，可能恰好使原分式方程的分母为零。这个解在整式方程中有意义，但在原分式方程中无意义，叫做增根，必须舍去！

But（增根示例）

例：解 (x+1)/(x-1) = 2/(x-1)

LCD = (x-1)，两边×(x-1)
x+1 = 2 → x = 1
验根：x=1 代入分母 (x-1) = 0！！分母为零！
✗ x=1 是增根，必须舍去！原方程无解。

Therefore（增根判断规则）

✅ 有效解

解 x = k 代入所有分母，分母均 ≠ 0

→ 保留该解

❌ 增根（舍去）

解 x = k 代入某个分母，使分母 = 0

→ 舍去该解，注明"原方程无解"

⚠️ 黄金法则：解分式方程必须验根！

不验根是解分式方程最严重的错误，会导致答案错误。每次都要检验解是否使分母为零。

知识精讲

分式方程

分母中含未知数的方程叫分式方程。解法是两边同乘最简公分母化为整式方程，解出后必须检验：使最简公分母为零的解是增根，必须舍去。增根来自“同乘可能为零的式子”这一步。

方法与范例

方法：去分母→解整式→必检验

先找最简公分母并写出使其不为零的条件；解完把根代回公分母检验。应用题还要检验是否符合实际意义。

范例：解 1/(x−1) = 2/x：交叉相乘得 x = 2(x−1)，x = 2x − 2，x = 2；x=2 不使分母为零，是原方程的解。

常见误区：常见误区是解完不检验，把增根当成答案。

📖 分式方程引入

And：学生已掌握整式方程解法

But：遇到分母含未知数的方程不会处理

Therefore：需要学习分式方程转化技巧

分式方程就是分母含有未知数的方程，比如 3/(x+2)=5。关键步骤是'去分母'：①找到所有分母的最简公分母(x+2)；②方程两边同时乘以公分母，得到3=5(x+2)。注意要检验根是否使原分母为零，比如x=-2就不是合法解。

🌍 就像调配消毒水时，原液和水的比例是1:x，现在知道2升原液配5升水，就能列出方程1/x=2/5来求解。
