- course_id：`info-u-signals-pbl`
- node_id：`ext-c84e21c6`（大学信息类核心课，课标树无对应节点，挂「其他知识」）
- lesson_type：`inquiry-project`
- 学习者画像：大学信息类专业核心课学生；已学高等数学、大学物理波动基础；常见卡点：把「开大音量」当成处理、把 FFT 点数当成分辨率、把滤波当成黑盒调参。
- ABT：
  - And：学生知道声音可以录音、放大、用软件「降噪」。
  - But：操场广播听不清时，放大往往更糟，学生说不出该动采样、频谱还是系统。
  - Therefore：从学生自己的问题出发，用可检验命题驱动采样、LTI/卷积、DFT/窗、FIR/IIR 四关。
- 问题锚点：
  1. 为什么把广播开得更响，字反而更糊？
  2. 语谱图上那条横线是什么？怎样只去掉它？
  3. 怎样证明一种处理比另一种更好，而不是「听起来还行」？
- 主交互：
  - 类型：问题分层板 + 四个 DSP 实验台（采样/卷积/频谱/滤波）+ Web Audio 对照听音
  - 学生操作：提出并升级问题；拖动采样率、窗长、截止频率；听 A/B/C/D
  - 系统反馈：混叠频率、Δf、线性检验、听感与指标对照
  - 学到什么：核心课深度来自可辩护的指标与推导，不是 Demo
- section 顺序：cover → 问题锚点 → 目标 → 提问工作坊 → 触发听音 → 前测 → 学期路径 → 采样理论+实验台 → LTI+卷积 → DFT+窗 → 滤波 → 关卡评价 → 自适应 → 后测 → 探究记录 → 图谱 → 学伴
- Bloom 覆盖：理解 / 应用 / 分析 / 评价 / 创造
- ConcepTest 位置：采样混叠、LTI、DFT 分辨率、相位失真 各 1
- 自适应四路：补前置（正弦与复数）/ 加支架（逐步推导）/ 正常推进 / 挑战（量化极点漂移或 DTMF）
