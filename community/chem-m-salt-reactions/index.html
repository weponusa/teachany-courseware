Core 1

盐 + 金属 → 新盐 + 新金属

已经知道：金属活动性顺序表 K Ca Na Mg Al Zn Fe Sn Pb (H) Cu Hg Ag Pt Au

但是问题是：为什么铁能把铜"挤"出来，而铜不能把铁"挤"出来？

所以这一段要解决：活泼金属能从盐溶液中置换出不活泼金属

Fe + CuSO₄ → FeSO₄ + Cu↓

🔑 反应条件

① 金属必须排在盐中金属的前面
② 盐必须是可溶的（溶液状态）
③ K、Ca、Na 太活泼，直接跟水反应，不适用

🧪 生活实例

• 铁钉浸入硫酸铜 → 表面变红（铜析出）
• 铜片浸入硝酸银 → 表面变白（银析出）
• 湿法炼铜：Fe + CuSO₄ = FeSO₄ + Cu

所以要掌握：复分解反应条件——必须有沉淀↓ / 气体↑ / 水生成

生成水

Core 3

盐+碱 和 盐+盐

盐 + 碱 → 新盐 + 新碱

CuSO₄ + 2NaOH → Cu(OH)₂↓ + Na₂SO₄

条件：反应物均可溶，且产物有沉淀生成

💡 蓝色沉淀 Cu(OH)₂ 可用于检验 Cu²⁺ 离子

盐 + 盐 → 两种新盐

NaCl + AgNO₃ → AgCl↓ + NaNO₃

条件：两种反应物均可溶，且产物有沉淀

💡 白色沉淀 AgCl 可用于检验 Cl⁻ 离子

🎯 复分解反应发生的核心条件：
反应物（至少一种）可溶 + 生成物中有 沉淀↓ 或 气体↑ 或 水

Worked Example

习题讲解：判断反应能否发生

📋 题目：向硫酸铜溶液中加入氢氧化钠溶液，判断能否反应？若能反应，写出化学方程式。

🔍 解题思路：

第1步：判断反应类型
硫酸铜（盐）+ 氢氧化钠（碱）→ 属于"盐+碱"类型

第2步：检查反应物可溶性
CuSO₄ 可溶 ✅ · NaOH 可溶 ✅ → 反应物均溶，满足条件

第3步：预测生成物并检查条件
交换阴阳离子 → Cu(OH)₂ + Na₂SO₄
查表：Cu(OH)₂ 不溶（生成沉淀↓）→ ✅ 满足复分解反应条件

第4步：写方程式并配平

CuSO₄ + 2NaOH → Cu(OH)₂↓ + Na₂SO₄

现象：产生蓝色沉淀

⚠️ 易错提示：如果生成物全部可溶且无气体无水生成，则反应不能发生。例如 NaCl + KNO₃ → NaNO₃ + KCl，产物全溶，不反应！

Summary

回顾：盐的四类反应

掌握了这四类反应规律和复分解反应条件，你就能预测绝大多数盐的化学行为。

01 盐+金属：活泼金属置换不活泼金属（前换后，盐须溶）
02 盐+酸：复分解反应（产物有↓/↑/H₂O）
03 盐+碱 / 盐+盐：反应物均可溶 + 产物有沉淀
🔑 核心条件：复分解反应能发生 ⟺ 产物中有沉淀↓、气体↑ 或水生成
知识精讲

盐的性质

盐是由金属离子（或铵根）与酸根离子构成的化合物。盐可与某些酸、碱、盐反应，也可与较活泼金属发生置换。学习时结合溶解性表判断能否发生复分解，并关注实际用途（如碳酸盐、盐业）。

方法与范例

方法：分类讨论反应对象

见盐先想：溶不溶？能与谁反应？产物中有无沉淀气体水？

范例：CuSO₄+2NaOH=Cu(OH)₂↓+Na₂SO₄，生成蓝色沉淀。

常见误区：常见误区是把碱性氧化物当成碱，或盐一定是咸的（化学“盐”≠食盐唯一）。

📖 盐的溶解性

And：学生知道食盐易溶于水

But：不同盐的溶解性差异极大

Therefore：掌握溶解规律才能预测反应

盐的溶解性有口诀：钾钠铵盐全都溶，硝酸盐类也相同。比如氯化银（AgCl）不溶于水——把硝酸银和食盐溶液混合会立即产生白色沉淀（AgCl↓），而同样含氯的氯化钠却完全溶解。记住：碳酸盐、磷酸盐大多不溶，除钾钠铵盐外。

🌍 热水壶水垢主要成分是碳酸钙（CaCO₃），它不溶于水。用醋（含醋酸）可以溶解水垢，因为醋酸能把它转化成可溶的醋酸钙。

📖 盐的复分解

And：学生见过酸碱中和反应

But：盐与盐反应需要双重条件

Therefore：理解离子交换的本质规律

复分解反应要同时满足两个条件：1.反应物必须可溶（除酸+盐情况） 2.生成物要有沉淀/气体/水。例如：氯化钡（可溶）+硫酸钠（可溶）→硫酸钡↓（白色沉淀）+氯化钠（可溶）。这个反应能发生就是因为生成了不溶的硫酸钡。

🌍 医院做钡餐检查时，患者喝下的硫酸钡（BaSO₄）悬浊液就是不参与复分解的安全盐——它既不溶于胃酸，也不会被人体吸收。
