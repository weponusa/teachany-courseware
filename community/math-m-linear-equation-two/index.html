📖 模块一：认识一元二次方程

And（从一次到二次）

你已经会解 2x + 3 = 7（一次方程，最高次数1）。现在面临一个新问题：

一块正方形土地面积为25m²，边长是多少？即：x² = 25

这里 x 的最高次数是 2！这就是一元二次方程。

But（为什么更难？）

一次方程只有一个解，而二次方程最多有两个解！x² = 25 → x = 5 或 x = -5。

Therefore（标准形式）

ax² + bx + c = 0   （a ≠ 0）

其中 a 是二次项系数，b 是一次项系数，c 是常数项。

例：将 2x² + 3x = 5 化为标准形式

→ 2x² + 3x - 5 = 0

a = 2，b = 3，c = -5

🔮 模块二：判别式 Δ = b² - 4ac

And（解的数量预判）

在用公式求解之前，我们可以先"预判"方程有几个实数解——这就是判别式 Δ（读作"Delta"）的作用。

Therefore（三种情况）

Δ = b² - 4ac
Δ > 0
两个不相等的实数根
x₁ ≠ x₂
Δ = 0
两个相等的实数根
x₁ = x₂（重根）
Δ < 0
没有实数根
（初中阶段无解）

🔭 示例计算

例：x² - 5x + 6 = 0（a=1, b=-5, c=6）

Δ = (-5)² - 4×1×6 = 25 - 24 = 1 > 0

→ 有两个不相等实数根 ✓

例：x² - 2x + 1 = 0（a=1, b=-2, c=1）

Δ = (-2)² - 4×1×1 = 4 - 4 = 0

→ 有两个相等实数根（重根）

🔢 模块三：求根公式法

And（解法的演变）

古人经过配方法推导，得到了一个通用公式，可以解任意一元二次方程！

Therefore（求根公式）

x = (-b ± √(b²-4ac)) / (2a)

其中 ± 表示"加或减"，所以有两个根 x₁ 和 x₂。

🔭 完整求解示例

解方程：2x² - 5x + 3 = 0

确定系数：a=2, b=-5, c=3
计算 Δ：Δ = (-5)² - 4×2×3 = 25-24 = 1 > 0，有两根
代入公式：x = (5 ± √1) / (2×2) = (5 ± 1) / 4
求两根：x₁ = (5+1)/4 = 6/4 = 3/2；x₂ = (5-1)/4 = 4/4 = 1
验算：代入原式：2×(3/2)²-5×(3/2)+3 = 9/2-15/2+3=0 ✓

🪞 错误诊断

❌ 常见错误：Δ = b² - 4ac，当 b 为负数时

b = -5：(-5)² = 25 ✓（注意加括号！）

错误做法：-5² = -25 ✗（符号算错）

✅ 永远对 b 加括号：(-b)² ！

  3. 展开：x² + _____ = 40

  6. 用求根公式解出 x = _____（取正值）

✅ 参考答案

设宽 x，长 x+3，方程：x(x+3)=40

x² + 3x - 40 = 0

Δ = 9 + 160 = 169，√169 = 13

x = (-3±13)/2 → x₁=5，x₂=-8（舍负）

宽=5米，长=8米。验算：5×8=40 ✓

一元二次方程的图像与性质

一元二次方程y=ax²+bx+c的图像是一条抛物线。当a>0时，抛物线开口向上；当a<0时，抛物线开口向下。抛物线的顶点坐标为(-b/(2a), c-b²/(4a))，对称轴为直线x=-b/(2a)。例如，方程y=x²-4x+3的顶点坐标为(2, -1)，对称轴为x=2。通过图像可以直观地了解方程的性质，比如开口方向、顶点位置、对称轴等。此外，抛物线与x轴的交点即为方程的实数根，因此通过图像可以判断方程的根的情况：有两个交点时Δ>0，有一个交点时Δ=0，无交点时Δ<0。

判别式与根的关系

判别式Δ=b²-4ac决定方程ax²+bx+c=0的根的性质。当Δ>0时，如x²-5x+6=0（Δ=1）有两个不同实数根2和3；Δ=0时，如x²-4x+4=0（Δ=0）有重根x=2；Δ<0时，如x²+x+1=0（Δ=-3）无实数根。物理中的抛体运动高度公式h=-5t²+20t，令h=0解得Δ=400，说明物体两次经过地面（t=0和4秒）。通过判别式分析，学生能快速预判方程解的情况，这对后续学习复数也有铺垫作用。

知识精讲

一元二次方程

形如 ax² + bx + c = 0（a≠0）的方程叫一元二次方程。判别式 Δ = b² − 4ac 决定根的情况：Δ＞0 有两个不相等实数根，Δ=0 有两个相等实数根，Δ＜0 无实数根。

方法与范例

方法：先化一般式再算判别式

务必先把方程整理成 ax²+bx+c=0 的形式，确认 a≠0，再代入 Δ = b²−4ac。含参数时用 Δ 的符号建立不等式求参数范围。

范例：x² − 4x + 1 = 0 中 Δ = (−4)² − 4×1×1 = 12 ＞ 0，方程有两个不相等的实数根。

常见误区：常见误区是没化成一般式就代公式，或忽略二次项系数 a≠0 这一前提。

📖 认识标准形式

And：学生已掌握一元一次方程解法

But：遇到含x²的方程不会判断标准形式

Therefore：明确一元二次方程的定义特征

一元二次方程的标准形式是ax²+bx+c=0（a≠0）。就像身份证必须有姓名和号码一样，必须包含x²项且最高次是2次。例如：2x²-5x+3=0中，a是2，b是-5，c是3。特别注意：当方程整理成3x=5x²-2时，要移项变成-5x²+3x+2=0才符合标准。

🌍 篮球抛出的轨迹就是二次函数，当球离手瞬间的抛物线可以用h=-5t²+vt+h₀表示，其中t是时间，h是高度。

📖 配方解法

And：已会解(x+m)²=n类方程

But：遇到x²+6x=7不知如何配方

Therefore：掌握将一般式转化为完全平方

配方法就像给多项式'补衣服'，把x²+bx配成(x+b/2)²。关键步骤：①保留x²系数为1（如2x²+8x=5先化为x²+4x=2.5）；②加上(b/2)²（如x²+6x加上(6/2)²=9）；③两边同时加。例：解x²-4x=5，配方得x²-4x+4=5+4→(x-2)²=9→x=5或-1。

🌍 就像调整蛋糕配方，原味面团（x²+6x）加入特定量糖（+9）就变成完美造型（(x+3)²）。
