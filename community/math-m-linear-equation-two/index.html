📖 模块一：认识一元二次方程

And（从一次到二次）

你已经会解 2x + 3 = 7（一次方程，最高次数1）。现在面临一个新问题：

一块正方形土地面积为25m²，边长是多少？即：x² = 25

这里 x 的最高次数是 2！这就是一元二次方程。

But（为什么更难？）

一次方程只有一个解，而二次方程最多有两个解！x² = 25 → x = 5 或 x = -5。

Therefore（标准形式）

ax² + bx + c = 0   （a ≠ 0）

其中 a 是二次项系数，b 是一次项系数，c 是常数项。

例：将 2x² + 3x = 5 化为标准形式

→ 2x² + 3x - 5 = 0

a = 2，b = 3，c = -5

🔮 模块二：判别式 Δ = b² - 4ac

And（解的数量预判）

在用公式求解之前，我们可以先"预判"方程有几个实数解——这就是判别式 Δ（读作"Delta"）的作用。

Therefore（三种情况）

Δ = b² - 4ac
Δ > 0
两个不相等的实数根
x₁ ≠ x₂
Δ = 0
两个相等的实数根
x₁ = x₂（重根）
Δ < 0
没有实数根
（初中阶段无解）

🔭 示例计算

例：x² - 5x + 6 = 0（a=1, b=-5, c=6）

Δ = (-5)² - 4×1×6 = 25 - 24 = 1 > 0

→ 有两个不相等实数根 ✓

例：x² - 2x + 1 = 0（a=1, b=-2, c=1）

Δ = (-2)² - 4×1×1 = 4 - 4 = 0

→ 有两个相等实数根（重根）

🔢 模块三：求根公式法

And（解法的演变）

古人经过配方法推导，得到了一个通用公式，可以解任意一元二次方程！

Therefore（求根公式）

x = (-b ± √(b²-4ac)) / (2a)

其中 ± 表示"加或减"，所以有两个根 x₁ 和 x₂。

🔭 完整求解示例

解方程：2x² - 5x + 3 = 0

确定系数：a=2, b=-5, c=3
计算 Δ：Δ = (-5)² - 4×2×3 = 25-24 = 1 > 0，有两根
代入公式：x = (5 ± √1) / (2×2) = (5 ± 1) / 4
求两根：x₁ = (5+1)/4 = 6/4 = 3/2；x₂ = (5-1)/4 = 4/4 = 1
验算：代入原式：2×(3/2)²-5×(3/2)+3 = 9/2-15/2+3=0 ✓

🪞 错误诊断

❌ 常见错误：Δ = b² - 4ac，当 b 为负数时

b = -5：(-5)² = 25 ✓（注意加括号！）

错误做法：-5² = -25 ✗（符号算错）

✅ 永远对 b 加括号：(-b)² ！

一元二次方程的定义与标准形式

一元二次方程是指只含有一个未知数，且未知数的最高次数为2的整式方程。其标准形式为ax²+bx+c=0（a≠0），其中a、b、c为常数，x为未知数。例如，方程2x²+3x-5=0就是一个标准的一元二次方程，其中a=2，b=3，c=-5。在实际生活中，一元二次方程可以用来描述许多现象，比如物体自由落体的高度随时间变化的规律，就可以用h=gt²/2来表示，其中h是高度，g是重力加速度，t是时间。将方程整理为标准形式，即为gt²/2-h=0。

一元二次方程的解法——直接开平方法

直接开平方法适用于形如x²=p（p≥0）或(ax+b)²=p（p≥0）的一元二次方程。例如，解方程x²=9，可以直接开平方得到x=±3。再比如，解方程(2x-1)²=16，可以先开平方得到2x-1=±4，然后解两个一元一次方程：2x-1=4和2x-1=-4，分别得到x=2.5和x=-1.5。需要注意的是，如果方程右边是负数，比如x²=-4，那么在实数范围内无解，因为任何实数的平方都是非负数。

一元二次方程的解法——配方法

配方法是将一元二次方程通过配方转化为完全平方形式，然后利用直接开平方法求解。例如，解方程x²+6x+5=0，可以先将常数项移到右边：x²+6x=-5。然后配方，即在方程两边加上一次项系数一半的平方：(6/2)²=9，得到x²+6x+9=4，即(x+3)²=4。最后开平方得到x+3=±2，解得x=-1或x=-5。配方法的关键是找到合适的数使左边成为完全平方式，这对于任何一元二次方程都适用，但计算过程可能较为复杂。

一元二次方程的解法——公式法

公式法是通过求根公式x=[-b±√(b²-4ac)]/(2a)来解一元二次方程。例如，解方程3x²-5x-2=0，首先确定a=3，b=-5，c=-2。然后计算判别式Δ=b²-4ac=(-5)²-4×3×(-2)=25+24=49。因为Δ>0，方程有两个不相等的实数根：x=[5±√49]/6，即x=(5+7)/6=2和x=(5-7)/6=-1/3。公式法适用于所有一元二次方程，但需要注意判别式的值：Δ>0时有两个实数根，Δ=0时有一个实数根，Δ<0时无实数根。

一元二次方程的解法——因式分解法

因式分解法是将一元二次方程化为两个一次因式的乘积等于零的形式，然后利用零乘积性质求解。例如，解方程x²-5x+6=0，可以将其因式分解为(x-2)(x-3)=0，从而得到x-2=0或x-3=0，即x=2或x=3。再比如，解方程2x²+7x+3=0，可以尝试分解为(2x+1)(x+3)=0，解得x=-0.5或x=-3。因式分解法适用于容易分解的方程，但对于某些方程可能难以找到合适的因式分解形式，此时需要改用其他方法。

一元二次方程的根与系数的关系

对于一元二次方程ax²+bx+c=0（a≠0），设其两个根为x₁和x₂，则有x₁+x₂=-b/a，x₁x₂=c/a。这称为韦达定理。例如，方程x²-5x+6=0的两个根为2和3，验证得2+3=5=-(-5)/1，2×3=6=6/1。韦达定理在不解方程的情况下，可以帮助我们了解根的性质。比如，如果c/a为正，则两根同号；如果c/a为负，则两根异号。此外，韦达定理还可以用于构造方程，例如已知两根为1和-2，则方程为x²-(1-2)x+1×(-2)=0，即x²+x-2=0。

一元二次方程的实际应用

一元二次方程在实际生活中有广泛的应用。例如，在几何问题中，已知一个长方形的面积为24平方米，长比宽多2米，求长和宽。设宽为x米，则长为(x+2)米，根据面积公式得x(x+2)=24，整理为x²+2x-24=0。解这个方程得x=4或x=-6（舍去负值），因此宽为4米，长为6米。再比如，在物理中，抛体运动的轨迹可以用二次函数描述，求解抛体的最大高度或落地时间等问题时，往往需要解一元二次方程。

一元二次方程的图像与性质

一元二次方程y=ax²+bx+c的图像是一条抛物线。当a>0时，抛物线开口向上；当a<0时，抛物线开口向下。抛物线的顶点坐标为(-b/(2a), c-b²/(4a))，对称轴为直线x=-b/(2a)。例如，方程y=x²-4x+3的顶点坐标为(2, -1)，对称轴为x=2。通过图像可以直观地了解方程的性质，比如开口方向、顶点位置、对称轴等。此外，抛物线与x轴的交点即为方程的实数根，因此通过图像可以判断方程的根的情况：有两个交点时Δ>0，有一个交点时Δ=0，无交点时Δ<0。

一元二次方程的实际应用

一元二次方程在现实生活中有广泛应用。例如在建筑设计中，抛物线形状的拱门可以用二次方程描述。设拱门最高点距地面6米，跨度12米，方程为y=-1/6x²+6（x∈[-6,6]）。在经济学中，利润最大化问题也常转化为二次函数求顶点。假设某商品利润P=-0.5x²+60x-500（x为销量），通过求顶点坐标(60,1300)可知最佳销量为60件时利润最大1300元。这类建模能帮助学生理解数学的工具性价值。

判别式与根的关系

判别式Δ=b²-4ac决定方程ax²+bx+c=0的根的性质。当Δ>0时，如x²-5x+6=0（Δ=1）有两个不同实数根2和3；Δ=0时，如x²-4x+4=0（Δ=0）有重根x=2；Δ<0时，如x²+x+1=0（Δ=-3）无实数根。物理中的抛体运动高度公式h=-5t²+20t，令h=0解得Δ=400，说明物体两次经过地面（t=0和4秒）。通过判别式分析，学生能快速预判方程解的情况，这对后续学习复数也有铺垫作用。

💡 错因诊断

错因：学生在解一元二次方程时，常常忽略a≠0的条件，或者忘记考虑判别式Δ的情况。误区：认为所有一元二次方程都有实数解，或者认为因式分解法适用于所有方程。诊断：需要通过大量练习和具体例子，帮助学生理解不同解法的适用条件，并强调判别式的重要性。
