1 · 气体模型

压强从哪里来？

把气体看成大量不断运动的微小分子。分子撞击容器壁，就会对器壁产生力；单位面积上平均撞击作用的强弱表现为压强 p。

  • 温度升高：分子运动更快，撞击更强；
  • 体积变小：同样多分子在更小空间内更频繁撞壁；
  • 充入更多气体：撞壁的分子数增多。

理想气体的简化

在温度不太低、压强不太高时，可近似认为分子体积和分子间作用力相对很小。

模型不是“真实照片”，而是帮助我们抓住 p、V、T、n 关系的工具。

2 · 玻意耳定律

温度不变时：体积减小，压强增大

一定质量气体、温度不变时，压强与体积成反比。

p₁V₁ = p₂V₂

条件要圈出

温度不变，气体质量不变。两个条件缺一个，就不能直接使用这个式子。

生活解释

堵住注射器出口后推活塞，V 变小；分子更频繁撞壁，因此 p 变大。

3 · 查理定律

压强不变时：温度升高，体积增大

一定质量气体、压强不变时，体积与热力学温度成正比。

V₁ / T₁ = V₂ / T₂

关键：比例关系从绝对零度开始计量，所以 T 必须使用开尔文（K），不能直接把 ℃ 代入。

例题 1 · 恒温

体积减半，压强怎样变？

20 ℃ 时，气体体积 V₁ = 4.0 L、压强 p₁ = 1.0×10⁵ Pa。温度不变，压缩到 V₂ = 2.0 L，求 p₂。

  1. 条件为温度不变、气体质量不变，选 p₁V₁ = p₂V₂。
  2. p₂ = p₁V₁/V₂。
  3. p₂ = 1.0×10⁵ × 4.0/2.0 = 2.0×10⁵ Pa。
例题 2 · 恒压

升温时体积怎样变？

气体在 27 ℃ 时体积为 3.0 L，保持压强不变加热到 127 ℃，求末体积。

  1. 先换温度：T₁ = 300 K，T₂ = 400 K。
  2. 压强不变，选 V₁/T₁ = V₂/T₂。
  3. V₂ = 3.0 × 400/300 = 4.0 L。
例题 3 · 状态方程

单位统一后再计算

0 ℃、p = 1.01×10⁵ Pa 时，2.0 mol 理想气体的体积是多少？取 R = 8.31 J/(mol·K)。

  1. T = 0 + 273 = 273 K；p 已是 Pa。
  2. V = nRT/p = 2.0×8.31×273/(1.01×10⁵) m³。
  3. V ≈ 0.0449 m³ = 44.9 L。

错因诊断

四个高频误区

温度直接用 ℃

比例定律必须使用绝对温度 K，否则零点被错放。

单位没有配套

用 R = 8.31 时，p 要用 Pa，V 要用 m³。

忘记 n 是否改变

打气时气体质量增加，不能把 pV 当作常数。

只背“反比”

p 与 V 成反比需要温度、气体质量不变这两个条件。

知识精讲

理想气体状态方程

实验发现气体的压强、体积和温度之间存在确定关系：温度不变时 pV 为常数（玻意耳定律），体积不变时 p 与热力学温度成正比，压强不变时 V 与热力学温度成正比。综合起来得到理想气体状态方程 pV = nRT，T 必须用开尔文温标。

方法与范例

方法：先判哪个量不变，再套对应关系

解题先读出“等温、等容还是等压”，再用相应的比例式，例如等温过程用 p₁V₁ = p₂V₂。温度必须换算为热力学温度：T = t + 273 K。

范例：等温压缩：p₁ = 1.0×10⁵ Pa、V₁ = 2 L，压缩到 V₂ = 1 L 时 p₂ = p₁V₁/V₂ = 2.0×10⁵ Pa。

常见误区：常见误区是直接把摄氏温度代入方程，忘记换算成开尔文。

📚 深度理解

🔍 易错点辨析

1. 混淆温度单位：学生常将摄氏温度直接代入理想气体方程计算。

例如计算25℃下1mol气体的体积时，错误使用298K而非298.15K。

根源在于不理解热力学温度是绝对标度，而摄氏温度是相对标度。

正确做法是严格遵守T=273.15+t的换算关系，尤其在精确计算中0.15K的差异会影响结果。

2. 忽视单位统一：解题时可能将kPa与Pa、L与m³混用。

典型错误如将200kPa×2L=1mol×8.314J/(mol·K)×300K，未将kPa转换为Pa导致结果差1000倍。

这源于对国际单位制理解不深，必须牢记标准单位是Pa和m³，1m³=1000L，1atm=101325Pa。

3. 误用常数R值：常见错误是忘记R有8.314J/(mol·K)和0.0821L·atm/(mol·K)等不同版本。例如在压强用atm、体积用L时错误选用8.314。这反映出对"方程两边单位必须匹配"原则的忽视，解题时应根据题目给定单位选择对应R值。

🌏 生活与科技中的应用

1. 高压锅设计：家用高压锅通过升高压强至2atm（约202kPa）使沸点升至120℃。工程师利用pV=nRT计算密封后加热时的压力变化，确保安全阀在临界压力（通常2.5atm）时自动泄压，这个数值直接来自理想气体状态方程的温度-压强关系。

2. 气象气球升空：科研气球在20℃充入500m³氦气（约2.2×10⁴mol），升至平流层时-60℃、0.1atm条件下体积膨胀至约1.2×10⁵m³。气象学家通过实时监测p、V、T数据，结合方程反推大气参数，误差控制在3%以内。

3. 人工呼吸机校准：ICU中呼吸机需精确控制潮气量（成人约500mL/次）。工程师根据p₁V₁/T₁=p₂V₂/T₂，在37℃体温、1.03atm胸腔压力下调整送气参数，确保肺泡获得标准状况（STP）下400mL有效气体交换量。

📖 知识脉络梳理

从波义耳1662年发现p∝1/V的定量关系开始，到1787年查理揭示V∝T的规律，再到1802年盖-吕萨克提出p∝T的结论，科学家们逐步拼凑出气体行为的完整图景。

1834年克拉珀龙将这些经验定律统一为pV=nRT的完美形式，其中R=8.314J/(mol·K)的普适常数直到20世纪才通过分子运动论得到微观解释。

具体应用中，先要明确四个核心变量：压强p的国际单位是帕斯卡（1Pa=1N/m²），标准大气压1atm=101325Pa；

体积V需用立方米（1m³=1000L），尤其在计算n=V/Vm时，标准状况下摩尔体积Vm=22.4L/mol；

物质的量n永远以mol为单位；

温度T必须用开尔文温标，水三相点精确定义为273.16K。

解决实际问题时，先判断过程类型：恒温过程用p₁V₁=p₂V₂，如注射器缓慢压缩；

恒压过程用V₁/T₁=V₂/T₂，如开口试管加热；

恒容过程用p₁/T₁=p₂/T₂，如密封罐日光暴晒。

对于综合变化，例如从25℃、1atm的10L氢气冷却到-50℃、2atm，就需完整代入pV=nRT，先换算-50℃=223K，再计算最终体积V₂=p₁V₁T₂/(T₁p₂)=3.58L。

典型计算如确定氧气瓶容量：40L钢瓶在15MPa、20℃时储存的氧气质量，先换算15MPa=1.5×10⁷Pa，293K，根据n=pV/RT≈246mol，乘以32g/mol得到约7.87kg。这种计算在医疗供氧、潜水气瓶管理中具有重要实用价值。

⚠️ 常见误区

误区一：认为温度升高体积一定增大。实际上理想气体状态方程 pV=nRT 涉及三个变量，若压强同时增大，体积可能不变甚至减小——必须控制变量分析。误区二：把 pV/T=常数 当成无条件成立。它只在气体质量不变（封闭系统）时成立；给气球打气时质量在变，不能直接套用。误区三：混淆摄氏温度与热力学温度。代入公式前必须把 ℃ 换算成 K（T=t+273.15），否则零度附近计算会完全错误。做题时先写已知量、统一单位、确认系统封闭，再列方程。
